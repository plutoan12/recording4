# 분리 실패 계측·화자 재검사·DiCoW·새 표본 검증

## 분리 실패 원인 정정

이전 보고서의 '4단계 추가 회복 없음'은 실행 경로를 구분하지 않은 설명입니다. 이번 계측으로 다음을 확인했습니다.

- 25% 겹말 및 같은 조건+10dB 잡음: 각 7개 분석 구간에서 분리를 실행했습니다. 각 조건의 8개 채널/대사 후보 모두 목소리 일치 점수가 0.6에 미달했습니다. 이 중 화자 점수 차이 부족은 각각 4/3건, 대사 일치율 0.85 미만은 각각 4/4건입니다. 이유는 중복 집계합니다.
- 대사가 잘 맞는 후보도 목소리 점수 0.35~0.57 범위여서 채택되지 않았습니다. 0.6은 미보정 문턱입니다. 이 표본에 맞춰 문턱을 낮추지 않았습니다.
- 50% 겹말 두 조건: 한 화자의 깨끗한 기준 음성을 확보하지 못하여 **분리 모델을 실행하기 전에 중단**했습니다. 이를 '분리 모델이 실제로 실패했다'고 표현하면 안 됩니다.
- 분리 뒤 기준 음원에 대한 선형 투영도 진단했습니다. 한 채널에서 설명되지 않는 에너지 비율이 99% 이상이므로 그 채널의 투영 기반 잔여 혼합 비율을 신뢰할 수 없습니다. 지연·위상·비선형 왜곡과 실제 누출을 이 지표 하나로 구분하지 않습니다. 주관적 청취로 혼합 정도를 판정한 것은 아닙니다.

진단은 채널별 목소리 점수/차이, ASR 일치율, 정렬 탈락, 두 채널 충돌, 기준 음성 부재, 변경 수를 구분합니다. 원문 전사와 분석 WAV는 비공개 audit 폴더에만 남기며 공개 JSON에는 수치만 저장합니다. 정답 개별 음원은 **추론 이후 진단에만** 사용했습니다.

## 기존 배정 재검사

`--reconsider` 옵션은 실제 겹말과 겹치는 단어만 수정 후보로 삼습니다. 목소리·대사 검증과 두 정렬 결과의 화자/시각 일치를 통과해야 수정하며 이전 화자를 기록하고 검수 표시를 유지합니다. 충돌하면 원래 배정을 보존합니다. 겹말 밖의 단어와 승인된 과거 버전은 수정하지 않습니다.

재검사 경로는 이미 탈락한 3단계 재정렬을 건너뛰고 현재 기본 1·2단계 결과에서 시작합니다. 운영 작업에는 자동 연결하지 않습니다.

같은 11조건 4,389자를 다시 검사한 결과 **정답 3,767 / 오배정 109 / 미확인 513**으로 승인된 1·2단계와 같습니다. 이미 배정된 화자가 실제로 바뀐 건수는 0입니다. 검증 문턱을 낮춰 정답 증가로 포장하지 않습니다. 조건별 SHA와 결과는 `regression.json`에 있습니다.

## 새 표본: 지표를 섞지 않음

FLEURS의 고정 리비전 `70bb2e84b976b7e960aa89f1c648e09c59f894dd`에서 언어별 앞 30개를 제외한 새 3개씩을 사용했습니다. 원본 파일명과 SHA는 `new-samples.json`에 있습니다. 낭독 12개는 실제 대화나 겹말 데이터가 아닙니다. 제공 메타데이터에 고유 화자 ID가 없어 12명의 서로 다른 화자라고 주장하지 않습니다.

| 언어 | 새 낭독 수 | 원문 문자 | Whisper small 오류 | CER |
|---|---:|---:|---:|---:|
| 한국어 | 3 | 171 | 20 | 11.7% |
| 영어 | 3 | 211 | 1 | 0.47% |
| 일본어 | 3 | 127 | 23 | 18.1% |
| 중국어 | 3 | 121 | 20 | 16.5% |

CER은 NFC 정규화 후 공백·문장부호를 제거하고 대소문자를 통일한 편집 거리입니다. 같은 규칙으로 모델을 비교합니다. CER과 화자 문자 정답 비율·DER은 다른 지표입니다.

실제 대화는 [AMI](https://huggingface.co/datasets/diarizers-community/ami) `ihm/test` 첫 행의 앞 120초를 사용했습니다. 새 평가 화자 ID 4명이며 기존 LibriSpeech 두 화자와 다른 자료입니다. 사람이 주석한 발화 합은 38.92초, pyannote 예측 화자는 2명, DER은 **34.49%**였습니다(collar 0, 겹말 포함; pyannote.metrics의 reference/hypothesis 범위 합집합 기준). 미검출 7.437초·화자 혼동 4.867초·오검출 1.119초입니다. 모든 모델의 학습 데이터에 없었던 화자라는 보장은 없습니다. 실제 한·일·중 대화 품질까지 확인한 것은 아닙니다.

## DiCoW 실행 및 재현

- 공식 체크포인트: `BUT-FIT/DiCoW_v3_2`, 리비전 `00a09c622bf58c34fdc76c3b5676f4da706f2a8e`, CC-BY-4.0. [모델 설명](https://huggingface.co/BUT-FIT/DiCoW_v3_2), [공식 추론 코드](https://github.com/BUTSpeechFIT/DiCoW).
- 기존 pyannote 예측 구간에서 Silence/Target/Non-target/Overlap 마스크를 만듭니다. 겹말 참조 화자 순열은 평가용 라벨 대응에만 쓰며 예측 마스크를 정답으로 교체하지 않습니다. 대본은 모델 입력에 넣지 않고 추론 후 점수 계산에만 씁니다.
- 최신 공식 앱 요구사항의 Transformers 4.55는 이 체크포인트의 옛 Whisper 내부 API와 맞지 않았습니다. 전이 상대 import 캐시도 보완했습니다. 체크포인트 설정과 맞는 4.42.4 및 전용 의존성은 `scripts/requirements-dicow.txt`에 고정했습니다. 운영 환경에는 설치하지 않습니다.
- FP32 eager는 메모리 제한으로 중단, FP16 SDPA는 CPU 추론이 느려 중단했습니다. CPU 동적 INT8 양자화/SDPA 경로로 비교하며 결과에 실행 설정을 구분합니다. 메모리 한계로 CTC 0.3 설정의 첫 두 한국어 표본만 끝났고 연속 실행이 종료 코드 137로 중단됐습니다. 본 비교는 CTC 보조 점수 가중치 **0.0**, greedy decoding, 최대 200토큰으로 전체를 새로 실행합니다. 모델이 남기는 임시 상태는 표본 사이에 해제합니다. 이 CPU 양자화 설정의 결과를 공식 모델 성능으로 일반화하지 않습니다.
- `scripts/run_dicow_benchmark.py`는 준비된 모델·벤치마크 전용 음원만 읽기 전용 마운트하고 `--network none`으로 실행합니다. 운영 비밀 환경 파일은 전달하지 않습니다. `--quantize`로 실제 실험 설정을 선택합니다.
- 기존 11조건: `verify_overlap_review.py --stage 4 --reconsider ...`; 진단 요약: `summarize_separation_audit.py`; 새 자료 기준: `evaluate_new_speech.py`; DiCoW 입력: `prepare_target_asr_manifest.py`, `prepare_overlap_target_manifest.py`.

FLEURS와 AMI는 CC-BY-4.0이며 [FLEURS 원본](https://huggingface.co/datasets/google/fleurs), [AMI 원본](https://groups.inf.ed.ac.uk/ami/corpus/)을 출처로 남깁니다. 원시 음원·전사·모델 가중치는 커밋하지 않습니다.

## 새 낭독에서 DiCoW 비교 결과

같은 12개 음원·원문·정규화 기준으로 측정했습니다. 단독 화자 전체 구간 마스크를 사용했으므로 이 표는 다국어 인식 비교이며 겹말 대응 효과를 측정한 표가 아닙니다.

| 언어 | Whisper small 오류/문자 | DiCoW INT8 오류/문자 | CER 변화 |
|---|---:|---:|---:|
| 한국어 | 20/171 | 10/171 | 11.70% → 5.85% |
| 영어 | 1/211 | 1/211 | 0.47% → 0.47% |
| 일본어 | 23/127 | 11/127 | 18.11% → 8.66% |
| 중국어 | 20/121 | 44/121 | 16.53% → 36.36% |

중국어는 번체·간체 표기 차이도 오류에 포함됩니다. 결과를 본 뒤 간체 변환을 적용해 채점 기준을 바꾸지 않았습니다. 언어별 표본 3개뿐이며 모델 크기·학습 데이터·디코딩 설정도 다르므로 향상을 화자 마스크만의 효과로 설명할 수 없습니다. 네 언어 공통 기본 모델 교체는 채택하지 않습니다.

## 같은 겹말에서 대상 화자 대사 비교

각 조건은 같은 음원 SHA와 같은 pyannote 예측 구간을 사용하며, 각 대상 화자 원문을 따로 채점해 합산합니다. 분모는 조건당 399자입니다. 순열 대응은 평가용으로만 사용하며 정답 대본이나 정답 활동 마스크를 모델 입력에 넣지 않습니다.

| 조건 | 예측 구간 마스크 + Whisper small | SepFormer + Whisper small | DiCoW INT8 |
|---|---:|---:|---:|
| 25% 겹말 | 80/399 (20.05%) | 110/399 (27.57%) | **6/399 (1.50%)** |
| 50% 겹말 | 155/399 (38.85%) | 기준 목소리 부재로 미실행 | **126/399 (31.58%)** |

표의 값은 **대사 문자 편집 오류/CER**입니다. 같은 문자를 다른 화자에게 배정한 109자와는 다른 평가입니다. SepFormer 수치는 저장된 채널의 원시 인식 결과이며 운영 검증 문턱을 통과했다는 뜻이 아닙니다. 50% 분리 미실행을 오류 0으로 계산하지 않습니다. 세 방식은 모델 크기와 디코딩 설정이 다릅니다(Whisper small INT8 beam 5, DiCoW INT8 greedy/CTC 0). 모델 구조만의 인과 효과를 분리한 실험은 아닙니다.

이 두 통제 조건에서는 대상 화자 대사 인식이 개선됐지만 50%의 오류가 여전히 31.58%입니다. 소음이 섞인 겹말의 DiCoW 비교, 실제 여러 사람 대화에서의 단어별 화자 재배정과 정답 증가/오배정 비증가 검증이 남아 있습니다. 운영에 자동 연결하지 않습니다.

## 재현 순서와 검증 범위

1. `fetch_fleurs_speech.py --language ko|en|ja|zh --count 3 --skip 30 --out <전용 디렉터리>`로 새 낭독을 준비합니다. AMI는 데이터셋 `ihm/test` 첫 행의 음원과 사람이 주석한 발화 시각/화자를 `ami-new/source.wav`, `reference.json`에 준비합니다. 원본·주석 SHA는 공개 결과에 기록했습니다.
2. 기존 캐시의 예측 화자 구간과 정렬 결과로 `verify_overlap_review.py --stage 4 --reconsider`를 실행합니다. 진단은 검사 출력 디렉터리 아래에서 자동 생성됩니다. `summarize_separation_audit.py --audits <검사 출력> --voices <원본 네 발화> --output <수치 JSON>`으로 공개용 진단을 만듭니다.
3. `prepare_target_asr_manifest.py`와 `prepare_overlap_target_manifest.py`의 입력 목록을 합칩니다. 전용 음원 루트에는 `new-ko-speech` 등과 `overlap/<조건>.wav`만 둡니다. 모델과 별도 의존성 디렉터리를 준비한 다음 `run_dicow_benchmark.py --model <고정 모델> --dependencies <별도 의존성> --manifest <목록> --audio-root <전용 음원> --output <결과> --quantize --ctc-weight 0`으로 실행합니다. 재개 시 음원 SHA, 참조 대사, 화자 마스크, 모델 리비전과 디코딩 설정이 같아야 결과를 재사용합니다.
4. `benchmark_masked_asr.py`는 같은 예측 구간의 타 화자 단독 부분만 0으로 만든 Whisper small 비교입니다. `--stems <audit 루트>`를 주면 저장한 SepFormer 채널을 인식합니다. 50% 두 조건은 분리 전 중단이므로 분리 인식 점수를 만들지 않습니다. CER 비교를 화자 배정 개선으로 간주하지 않습니다.

Python 전체 466 통과/5 조건부 skip, 변경 파일 Ruff 통과. 새 실험 모델·의존성은 운영 이미지에 설치하지 않았고 운영 기본 1·2단계는 유지합니다. 유료 호출·추가 영상 게시·원음 변경은 없습니다.
