# 순차 개선 1단계: 단어 화자 시간 지지 후보

운영 배정은 변경하지 않았다. `review_speakers(... minimum_word_coverage=0.8)` 실험 옵션과 실제 영어/11조건 평가 옵션을 구현했다. 기본0은 기존 동작이다. 기존 stage2 다수 기준80%를 한 화자 배정에도 적용하며 정답을 보고 수치를 튜닝하지 않았다.

배정된 화자의 구간 합집합이 단어 길이의80% 미만이면 미확인으로 남긴다. 중복 트랙으로 시간을 늘리지 않고 후보 화자/원문/시각을 보존한다. 앞뒤 대사만으로 화자를 추정하지 않는다. 재정렬·독립 목소리 확인으로 정답을 회복하는 경로까지 새로 구현한 것은 아니다.

## 실제 재채점

| 자료 | 기존 정답/오배정/미확인 | 후보 정답/오배정/미확인 |
|---|---:|---:|
| 영어 Community,801자 | 695 / 32 / 74 | 646 / 21 / 134 |
| 영어 Sortformer,801자 | 715 / 32 / 54 | 528 / 32 / 241 |
| 기존11조건,4,389자 | 3,767 / 109 / 513 | 3,700 / 109 / 580 |

**채택 보류.** 기존 영어 오배정11자를 차단하지만 정답49자도 잃는다. 기존11조건은 정답67자를 잃고 오배정은 그대로다. 오배정을 미확인으로 바꾼 것은 오류 복구/전체 정확도 증가가 아니다. 결과 파일은 전체 조건·분모를 보존한다.

영어는 사람 단어/시각의 oracle 진단이며 STT정확도가 아니다. 11조건은 원본 음원 재생성/캐시SHA를 확인한 기존 에너지 활동 기준이다. 모델/정렬 캐시를 재사용하고 새 음성 추론은 하지 않았다. 이미 본 평가 자료로 진단했으므로 독립 최종 검증으로 주장하지 않는다.

재현 옵션: `score_manual_word_speakers.py --minimum-word-coverage 0.8`, `verify_overlap_review.py --stage 2 --minimum-word-coverage 0.8`. 음원·단어·캐시는 비공개 폴더에만 둔다.

## 2단계 착수: 기준 목소리 부재 원인

저장된11조건 화자 구간에서 기존 기준 목소리 선정 규칙(다른 화자와 겹치지 않는0.5초 이상)을 다시 계산했다. 50% 겹말 두 조건에서 한 화자는 기준 구간이0초다. 같은 화자의 인접/중복 조각을 합쳐도 두 조건 모두0초로 유지되며 나머지9조건도 길이 변화가 없다. 따라서 조각 병합만으로 해결된다고 주장하거나 불필요한 모델 재추론을 하지 않았다.

이후 과제는 기존 단일 화자 구간 외의 음성에서 대상 화자를 독립 확인할 수 있는 근거 확보다. 현재 겹말 대상 화자의 깨끗한 기준이 없을 때 잘못된 목소리를 억지로 연결하면 안 된다. 등록된 깨끗한 기준 목소리 또는 두 모델의 구간을 이용한 음성 검증 후보를 별도 개발 자료에서 비교해야 한다. 이 후보는 미구현/미실측이다.

## 진행 상태와 후속

1. 단어 배정: 후보 구현·실제 재채점 완료, 품질 기준 미달로 운영 적용 보류.
2. 목소리 뒤바뀜: 기준 목소리0초 원인 확인, 독립 음성 검증 후보 미완료.
3. 작은 목소리/맞장구: 국소 재인식 후보 구현·검증 남음. 기존 전역 음량 보정 회귀는 유지한다.
4. 겹말 DiCoW: 기존50% 개선/25% 회귀를 유지하며 새 국소 적용 검증 남음. 대사 일치만으로 화자를 덮어쓰지 않는다.
5. 네 언어 검증: 한국어 사람 검수 및 독립 새 표본의 전체 지표 남음.
