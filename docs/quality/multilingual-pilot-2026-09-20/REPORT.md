# 원인별 비교와 새 실제 대화 파일럿

## 범위

사용자의 원인별 수정/새 한·일·중·영 실제 대화 검증 요청에 따라, 실제 자료를 확보하고 **고정 음량 보정 사본**과 **공식 긴 문맥 설정**을 비교했다. 세 언어 각 120초 파일럿이며 네 언어 검증 완료/운영 승인으로 표현하지 않는다. 대사 CER/문자 화자 정답률까지 측정한 것은 아니고 화자 시각의 DER을 측정한다.

- 중국어: [AliMeeting 공식 Eval](https://www.openslr.org/119/), 파일명순 첫 회의 R8001_M8004, far-field 채널0의 처음 120초. 네 화자 TextGrid의 비어 있지 않은 구간을 사용한다. 개발용 역할이며 독립 최종 test를 뜻하지 않는다. 자료 CC BY-SA 4.0. 약 3.42GiB 공식 묶음을 비공개 저장했다.
- 일본어: [J-CRe3](https://github.com/riken-grp/J-CRe3) 고정 리비전 test 목록의 첫 대화 20220302-56132034-1, 처음 120초. 공식 Box audio.wav/info.json/timestamp.json 확보. stereo 평균 → scipy resample_poly(160/441) → mono16kHz PCM16. 제공자가 표기한 ms 시각/화자/대사를 사용하고, GitHub 전사 시각 23개와 ms 정밀도로 일치 확인했다. 시나리오 기반 두 사람의 실제 발화이며 자발 회의와 구분한다. CC BY-SA 4.0.
- 영어: [diarizers-community/ami](https://huggingface.co/datasets/diarizers-community/ami) ihm/test row1의 처음 120초. 기존 진단 row0과 다르다. CC BY4.0 카드/원 AMI 출처를 따른다. 네 화자 시각 정답은 있으나 대사는 없어 CER/완전 코호트 입력으로는 부족하다.
- 한국어: [ETRI KMSAV](https://github.com/etri/kmsav) 공식 ASD v0.2 압축본을 실제 확인했다. 문장 전사/시각/얼굴 위치가 있으나 같은 사람을 문장 사이에 연결할 화자 ID가 없다. 얼굴 위치나 모델 추정으로 사람 정답을 만들지 않았다. 실제 다화자 검증에는 추가 사람 주석 또는 다른 정답 자료가 필요하다. 자료 CC BY-NC-SA4.0이며 운영 자산으로 반입하지 않는다.

모델의 학습에 이 코퍼스들이 포함될 수 있다. 새로운 로컬 표본이라는 뜻이며 학습 미포함 화자/독립 holdout으로 주장하지 않는다. 준비한 일부 자료로 완전 코호트 lock 검사를 우회하지 않고 `score_segments`의 별도 파일럿 결과로 남긴다.

## 시험한 원인과 수정 후보

1. **스트리밍 문맥 부족 가설:** 체크포인트 기본값(188/1/0/188/188)과 [NVIDIA v2.1 공식 high-latency 설정](https://huggingface.co/nvidia/diar_streaming_sortformer_4spk-v2.1)(340/40/40/300/188)을 명시적으로 구분했다. 순서는 chunk/right-context/fifo/update/cache다. `run_sortformer_evaluation.py --streaming-profile v21-high-latency`가 설정과 실제 값을 증거에 기록한다. 기본값은 checkpoint 그대로다. 기존 AMI 진단에서 누락 **18.91초 그대로**, DER **50.72% → 51.93%**로 악화해 개선안으로 채택하지 않았다. 이 결과는 실제 설치된 NeMo2.5 환경에 한하며 다른 버전의 결과를 보장하지 않는다.
2. **낮은 입력 음량 가설:** `prepare_analysis_gain.py`는 원음을 보존하고 분석 사본의 peak를 최대 -1dBFS 쪽으로 올리되 증폭을 20dB로 제한한다. 큰 입력은 줄이지 않고 무음은 무음으로 둔다. 모든 샘플 수/시각을 유지하며 정답/모델 결과를 입력받지 않는다. 중국어 8.7726dB, 일본어14.1353dB, 영어20dB가 적용됐다. 잡음도 같이 증폭하므로 **잡음 제거나 SNR 향상이 아니다**. 정한 수치로 단 한 번 비교했으며 평가 결과를 보고 목표값을 다시 맞추지 않았다.
3. **짧은 맞장구/겹말/긴 발화:** 이전의 고정 20ms 진단을 보존한다. 단순히 누락을 줄이는 조건만으로 채택하지 않고 무음 오검출과 화자 혼동도 같이 측정한다. 새 모델로 화자를 자동 덮어쓰지 않는다.

## 채점 기준과 결과 파일

모든 비교는 같은 원본에서 만든 120초 구간과 같은 사람 정답, collar0/겹말 포함/명시적 0–120초 UEM이다. 음량 사본은 원본 SHA와 출력 SHA를 별도 연결하고 원본이 같다고 허위 표기하지 않는다. 실패를 없애거나 분모를 변경하지 않는다. 원본·사본·주석·예측·입력 선정 lock SHA와 전체 세부 수치는 `results.json`에 저장한다. 원시 음원/전사/예측은 비공개 폴더에만 보존한다.

최종 수치와 검사 결과는 HANDOFF 및 results.json을 따른다. 운영 기본/유료 API/게시 변경은 없다.

## 실제 12회 결과

아래는 DER(낮을수록 좋음)이며 원음/음량 사본을 같은 모델·정답으로 비교했다. 각 언어 한 표본이므로 언어 전체 성능이나 언어별 자동 모델 선택 기준이 아니다.

| 언어 | Community-1 원음 → 사본 | Sortformer v2.1 원음 → 사본 |
|---|---:|---:|
| 중국어 | 10.890% → 10.861% | 13.033% → 12.202% |
| 일본어 | 54.760% → 54.705% | 18.577% → 16.569% |
| 영어 | 15.612% → 15.437% | 43.372% → 43.072% |

- 일본어 Community-1의 주요 오류는 화자 혼동 23.350초다. Sortformer 원음은 0.846초지만 누락은 8.521초로 Community-1 6.907초보다 많다. 두 결과를 무조건 합치거나 일본어라는 이유만으로 자동 교체하지 않는다.
- 영어 Community-1 음량 보정에서 화자 혼동 **0.087→0.205초**, 무음 오검출 **0.477→0.493초**로 증가했다. 일본어 Community-1은 누락 **6.907→6.942초**로 증가했다. 평균 DER만 보고 수정안을 승인할 수 없다.
- Sortformer 음량 사본은 세 표본의 누락/혼동이 줄었지만 일본어 무음 오검출 **1.568→1.937초**, 영어 **0.350→0.420초**가 증가했다. 낮은 입력 음량이 일부 영향을 주지만 전체 원인/완전 해결로 단정할 수 없다.
- 기존 AMI 긴 문맥 시험 1회와 새 원음/사본 12회는 모두 정상 종료했다. 일본어 준비 중 시스템 PATH에 ffmpeg가 없어 미실행된 두 호출은 로그로 보존하고, scipy 고정 리샘플링 입력 생성 후 재실행했다. 추론 도중 실패한 표본을 빼서 점수를 올린 것이 아니다.

## 구현·재현·검토

- `prepare_dialogue_pilot.py`는 제공자의 중국어 TextGrid/일본어 info.json/영어 AMI row를 고정 120초 DER 입력으로 변환한다. 자막 CER 정답과 혼동하지 않도록 대사를 출력에서 제외하고 complete_multilingual_cohort/deploy_allowed를 항상 false로 기록한다. **세 언어 음원 SHA와 화자·시각 목록을 최초 실행 입력과 똑같이 재현한 것을 확인했다.**
- 변환용 로컬 환경: soundfile0.13.1, praatio6.2.0, scipy. Sortformer는 기존 잠금 환경, Community-1은 별도 네트워크 차단 컨테이너와 읽기 전용 모델 캐시를 사용했다. 운영 워커나 비공개 토큰을 변경하지 않았다.
- Claude 검토에서 확인한 증거 파일의 불완전 JSON 생성과 음원 생성 시 권한 문제를 수정했다. JSON 직렬화에 실패하면 파일을 먼저 만들지 않고, 음량 사본을 처음부터0600으로 생성한다. 출력 peak는 PCM16 재읽기 실측, 보정 전 float peak는 별도 보존한다. 실제 실험 당시 메타데이터의 peak_after는 float 기준이므로 이 차이를 정확도 향상으로 해석하지 않는다.
- Python **594통과/6skip**, 변경 파일 Ruff 통과. 새 변환기 실제 파일3개 재현 완료. 시작 HEAD89063e8의 모든 필요한 CI 통과 확인. 이번 새 커밋의 CI는 별도 확인한다.
- 한국어 ASD 주석 **43,805개 전체**의 헤더를 점검했으나 화자 ID가 없었다. 사람이 검수한 한국어 화자 정답, 영어 대사 정답, 네 언어 고정 코호트의 CER/문자 화자 정확도, 후보의 기존11조건 회귀는 미완료다. 검증이 부족한 변경을 운영 기본에 넣지 않았다.

한국어 대안으로 [ETRI KEMDy20 공식 배포](https://epretx.etri.re.kr/dataDetail?id=318&lang=ko)도 확인했다. 현재 안내는 협약서가 필요하며 2026-04-13 배포본에 WAV가 포함되지 않는다고 명시한다. 임의 재배포 미러를 정답 자료로 대신 사용하지 않았다.
