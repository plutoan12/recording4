# 기준 음성 부재의 원인 분리

기존 누락 추가 실험의 같은 영어 120초 저장 예측과 같은 후보 시각으로 재계산했다. 정답을 선택에 사용하지 않았고 새 모델 추론·유료 호출은 없다. **이번 변경은 진단 개선이며 자막 정확도 개선은 아니다.**

| 모델·화자 | 조각 필터 전 단독 발화 | 짧은 조각 제외 | 후보 문맥 제외 | 최종 기준 후보 |
|---|---:|---:|---:|---:|
| Community 00 | 70.453초 | 1.163초 | 2.410초 | 66.881초 |
| Community 01 | 0초 | 0초 | 0초 | 0초 |
| Sortformer 0 | 48.070초 | 5.600초 | 0.560초 | 41.910초 |
| Sortformer 1 | 1.680초 | 1.040초 | 0초 | 0.640초 |
| Sortformer 2 | 0.240초 | 0.240초 | 0초 | 0초 |

Community 01의 전체 예측 1.85625초는 모두 다른 화자와 겹친다. 짧은 조각 제한 때문에 0초가 된 것이 아니다. Sortformer 1은 1.68초 단독 발화 중 1.04초가 0.5초 미만 조각으로 제외되고, 남은 0.64초는 총 1초 요건에 못 미친다. Sortformer 2 역시 사용 가능한 기준이 없다. 모델 간 익명 화자 번호는 서로 동일 인물이란 뜻이 아니다.

`anchor_availability()`로 전체 예측 합집합, 겹말 제외, 짧은 조각 제외, 후보±1초 문맥 제외, 남은 길이를 별도 기록한다. 같은 선택 함수를 실제 음성 검증에서도 사용한다. `eligible_duration_only`는 길이만 충분하다는 뜻이며 음성 순도나 신원을 승인하지 않는다. 기존 0.5초/1초/음성 유사도·차이 기준은 그대로다.

이전 실제 후보 유사도 0.1413과 별도 ASR 불일치도 여전히 남는다. 경쟁 음성만 확보해도 자동으로 통과하는 것은 아니다. 영어 고정 784자 CER 21.8112%/171오류는 이전 실측 그대로이며 이번에 새 정확도로 재측정한 수치가 아니다.

## 검증

실제 두 모델 모두 변경 전·후 기준 구간 선택이 완전히 같음을 확인했다. 전체 Python 622통과/7skip, 마지막 겹말 제외 계측 추가 후 관련 7개 재검사 통과, Ruff 통과. 입력 SHA와 집계는 [results.json](results.json)에 보존했다. 원시 대사·음원·임베딩은 포함하지 않았다. 시작 커밋 aa8ffaf의 Python/웹/DER CI 통과를 확인했고 당시 워커/스택 검사는 진행 중이었다.

## 다음 실험

현재 120초 안에서는 두 모델 모두 비교 가능한 기준 음성이 부족하다. 독립 개발 표본 또는 더 긴 동일 녹음의 추가 문맥에서 단독 발화 후보를 확보하고, 음성 일관성과 익명 ID 대응을 검증해야 한다. 정답 화자 정보를 기준 선정에 넣거나 0.64초를 통과시키도록 문턱을 낮추지 않는다. 추가 문맥은 기준 음성 확보에만 쓰고 기존 평가 120초/분모는 유지한다. 새 한국어 사람 정답과 네 언어 전체 비회귀 검증, PR37 누적 검토는 미완료다. 운영 변경 없이 초안을 유지한다.
