# 기존 대사 보존 + 누락 후보 추가 실험

## 결과

기존 Whisper 단어를 모두 보존하는 별도 실험 CLI를 구현했다. 실제 영어 AMI 120초의 후보는 1묶음 2단어이며 독립 근거 검사를 통과하지 못했다. **채택 0단어, 기존 출력 동일, 정확도 개선 미입증**이다. 운영 파이프라인은 변경하지 않았다.

| 전체 784자 고정 평가 | 일치 | 치환 | 삭제 | 삽입 | 총 오류 | CER |
|---|---:|---:|---:|---:|---:|---:|
| 기존 / 검증 후 출력 | 616 | 10 | 158 | 3 | 171 | 21.8112% |
| 검증 없이 후보를 추가한 사후 비교(미적용) | 621 | 11 | 152 | 3 | 166 | 21.1735% |

사후 비교는 후보의 가능성을 진단한 것이며 채택 성과가 아니다. 치환도 1개 늘었다. 정답을 보고 후보를 통과시키거나 기준을 낮추지 않았다. 이전 국소 DiCoW 115자/48칸 평가와 분모가 다르다.

## 방법과 실패 원인

- 이전 긴 문맥 실험의 30개 결과를 재사용했다. 두 정렬기 동의 12개 중 11개는 핵심 구간에 단어가 없었다. 남은 1개에서 기존 ASR 단어와 겹치지 않는 2단어를 정답 없이 선택했다.
- 기존 단어의 대사·시각·순서는 보존한다. 시각 길이 0인 기존 단어도 점유 구간으로 취급한다. 서로 충돌하는 추가 후보는 거부한다.
- 같은 예측 모델의 단독 발화에서 후보 앞뒤 1초를 제외하고 ECAPA 기준 음성을 구성했다. 0.5초 이상 조각, 총 1초 이상을 요구했다. 대상 후보 66.880625초, 다른 화자 0초였다. 이는 모델이 예측한 후보 길이이며 순수한 화자 음성임을 뜻하지 않는다.
- 0.68초 추가 후보의 대상 유사도는 **0.141324**로 고정 기준 0.6 미달이다. 비교 화자 음성이 없어 경쟁 화자 대비 차이는 계산할 수 없었다. 공개 결과에는 null로 기록했다.
- 별도 Whisper small CPU int8/beam5/VAD off/앞뒤 1초 재인식도 제안 대사와 일치하지 않았다. 완전 일치, 음성 유사도 0.6, 차이 0.15, 기준 음성 절반 간 검사를 모두 요구하며 실패 시 원본을 보존한다.
- Whisper 재인식은 DiCoW와 별도 실행이지만 모델 계열의 상관성이 있어 통계적으로 독립된 증명은 아니다. 시각 동의 역시 화자 신원의 증명이 아니다. 이 CLI는 현재 영어 전용이며 네 언어 검증으로 해석하지 않는다.

## 검증·재현

`prepare_additive_retry.py`는 원본 ASR/문맥 manifest/정렬 결과의 입력 SHA와 음원 동일성을 연결한다. `verify_additive_voice.py`는 음원 SHA를 재확인하고 로컬 캐시 ECAPA와 Whisper로 검증한다. 모델 캐시를 읽기 전용으로 연결한 네트워크 차단 컨테이너에서 실행했으며 유료 호출은 없다. ECAPA revision은 `0f99f2d0ebe89ac095bcc5903c4dd8f72b367286`이다.

첫 검증 이후 기준 음성 부재를 대상/경쟁 화자로 구분하는 진단을 추가해 한 후보를 재검사했다. 이후 0길이 기존 단어 보호 변경으로 준비 결과가 완전히 동일함을 확인했고 모델 재추론은 반복하지 않았다. 최종 출력이 첫 검증 및 기존 원본과 같은 것도 확인했다.

Python **620통과/7skip**, 변경 Ruff 통과. 새 5개 회귀는 원본 보존·충돌·정렬 실패·ASR 불일치·NaN·0길이 단어 보호를 검사한다. 코드 검사는 실제 음성 정확도 개선의 증거가 아니다. 원시 음원·전사·임베딩은 커밋하지 않았다. 공개 수치와 입력 지문은 [results.json](results.json), 비공개 실행물은 `recording4-evaluation-private/additive-retry-20260920`에 있다.

## 다음 작업

경쟁 화자 기준 음성 0초와 낮은 대상 유사도의 원인을 구분해야 한다. 전체 예측에 단독 발화가 없는지, 후보 혼합/익명 화자 대응 오류인지 독립 개발 자료로 확인한 뒤 대체 모델 기준 음성을 검증한다. 짧은 맞장구의 별도 재인식 불일치도 개발 자료에서 분석한다. 현재 평가 정답에 맞춰 문턱을 조정하지 않는다. 한국어 완전한 사람 정답과 새로운 네 언어 대화의 CER/DER/화자 오배정 비회귀 검증은 여전히 남아 있다. PR37 초안과 운영 기본값, 자동화 PAUSED를 유지한다.
