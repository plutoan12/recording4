# 독립 영어 대화의 경계 후보·확장 기준 검증

기존 영어 평가와 다른 AMI test row 2의 첫 120초를 개발 표본으로 고정했다. WAV 파일 해시만 다르고 디코딩 PCM이 같았던 두 선행 후보는 제외했다. 최종 표본의 PCM MD5는 기존 표본과 달랐고, 평가 음원 SHA-256은 `551f54bb9ecad533584992ff16eb18e5ff9b4520fd524b51ba557de53fbe37b6`이다. 원시 음원·대사·모델 출력은 비공개 `independent-boundary-dev3-20260920`에만 저장했다.

결론은 **경계 부분 합의와 확장 기준 연결은 독립 표본에서도 작동했지만, 채택 0단어로 정확도 개선은 미입증**이다. 후보 생성과 승인은 사람 정답을 사용하지 않았고 운영 자막·화자·모델 기본값은 변경하지 않았다.

## 고정 입력과 누락 후보

Community-1 revision `3533c8cf8e369892e6b79ff1bf80f7b0286a54ee`은 16발화·2화자, Sortformer v2.1 revision `fafaab5faa1617a0ca52d38dd3dc4bd636800d3d`은 34발화·3화자를 예측했다. Whisper small 원본은 78단어였다. 기존과 같은 단어 앞뒤 0.1초 보호·0.5초 최소 빈 구간 규칙을 적용해 두 모델 공통 음성에서 2구간·1.6초를 선택했다. Whisper 국소 재시도는 1그룹·2단어를 제안했지만 이 결과만으로 추가하지 않았다.

같은 2구간을 Community의 두 예측 화자에 대해 DiCoW로 4회 실행했다. 정답 대본은 입력하지 않았다. 두 정렬기 결과는 부분 합의 1, 완전 시각 합의 1, 잘못된 시각 1, 빈 출력 1이었다. 제외된 경계 단어가 다시 섞이지 않도록 선택 단어·시각만 다음 단계로 전달해 1그룹·7단어 후보가 됐다.

## 300초 확장 기준과 최종 거부

120초 안에서는 다른 화자의 3.459초 예측이 모두 겹말이라 경쟁 기준이 0초였다. 같은 회의 300초를 Community-1으로 다시 분석한 뒤 후보 대상 화자만 공유 구간의 시간 대응으로 검증했다. 대상 대응은 원래 coverage **98.019%**, 확장 예측 purity **99.667%**, 양방향 유일 최적으로 고정 80% 기준을 통과했다. 전체 원래 화자를 억지로 대응하지 않았으며 대상 대응 실패 시 확장 기준을 쓰지 않는 규칙이다.

120초 이후 단독 기준은 대상 **65.808초**, 경쟁 화자 **79.144초**였다. 음성 기준 상태는 `candidate_only`였지만 후보와 대상 기준의 ECAPA 유사도는 **0.2392 < 0.6**, 경쟁 화자 대비 차이는 **0.1235 < 0.15**였다. 별도 Whisper 대사도 불일치했다. 확장 음성이 대체한 과거 `unreliable_anchor`·`insufficient_voice_match` 사유는 제거했지만, 새 수치의 문턱 미달과 독립 ASR 불일치 때문에 채택은 0단어다.

이 결과는 경쟁 기준 부재가 해소돼도 현재 후보가 맞지 않는다는 더 강한 반증이다. 평가 결과를 보고 0.6/0.15 문턱을 낮추지 않았고 실패 구간을 분모에서 제거하지 않았다.

## 선정 후 공식 시각·ASR 신뢰도 진단

모든 후보 생성과 거부가 끝난 뒤 Hugging Face `diarizers-community/ami`가 제공하는 AMI 공식 화자 시각을 사후 진단에만 사용했다. 47.46~48.34초 후보는 어떤 사람 발화와도 겹치지 않았고, 앞선 발화는 30.24초에 끝나며 다음 발화는 50.13초에 시작한다. 따라서 이번 채택 0은 실제 공통 오검출을 막은 결과다. 이 정답 시각은 후보 선택·DiCoW·음성 검증 문턱에 입력하지 않았다.

Whisper 신뢰도로 더 일찍 거를 수 있는지도 같은 개발 회의에서 조사했다. 16개 공식 발화 중 국소 Whisper 단어가 나온 것은 13개였고, 10개 무발화 구간 중 문맥 단어가 걸친 것은 9개였다. 오검출 후보의 `no_speech_prob`/평균 로그확률은 **0.392/-0.987**이지만, 50.13~50.55초의 짧고 조용한 공식 발화는 **0.446/-1.017**로 더 불리했다. 오검출을 자르는 단순 문턱이 실제 발화도 함께 자르므로 적용하지 않았다. 국소 최대 20dB 증폭 뒤 Silero VAD도 두 구간을 모두 음성으로 보아 독립 veto로 쓰지 않았다.

따라서 다음 후보는 절대 신뢰도나 VAD 문턱 조정이 아니라, 잡음과 저음량 대사를 구분하는 별도 음향 근거를 개발 자료에서 만들고 다른 회의에서 고정 검증해야 한다.

## 구현과 검증

`run_community_evaluation.py`는 비공개 PCM16 16kHz mono 음원을 오프라인 Community-1으로 실행하고 입력 SHA·모델 revision·실행 시간을 고정한다. `verify_extended_anchor.py`는 제안된 대상 화자만 공유 구간에서 양방향 유일 대응하며, 확장 기준이 대체하는 과거 음성 사유만 제거한다. 독립 ASR 불일치·짧은 후보·알 수 없는 미래 사유는 그대로 유지한다. Hugging Face와 Transformers 오프라인 모드를 코드에서 강제한다.

유료 호출·게시·운영 변경은 없다. 전체 회귀와 CI 결과는 [HANDOFF](../../HANDOFF.md)에 기록한다. 새 네 언어 전체 정확도 개선은 여전히 입증되지 않았으며 PR #37은 초안으로 유지한다.

로컬 검증은 Python **670통과/2skip**, Ruff 검사·형식 검사 통과다. GitHub CI 결과는 커밋별로 PR #37에 보존한다.
