# 더 긴 동일 회의 기준 음성·분리 재인식 검증

기존 영어 AMI 평가 음원의 원본에서 앞 300초를 사용해, 평가 120초 밖에서 깨끗한 기준 음성을 더 확보할 수 있는지 검사했다. 300초 음원의 앞 120초가 기존 평가 음원과 디코딩 샘플 단위로 완전히 같음을 확인했다. 평가 구간·784자 분모·기존 자막은 변경하지 않았다.

결론은 **추가 후보 2단어 채택 0, 정확도 개선 미입증**이다. 더 긴 대상 화자 음성과 다른 화자 모델, 음성 분리 후 재인식까지 추가했지만 기존 음성·대사 검증을 통과하지 못했다.

## 동일 모델의 화자 대응과 기준 음성

Community 모델을 300초에 네트워크 차단·오프라인 캐시로 다시 실행했다. 51개 발화와 2개 익명 화자를 반환했으며 CPU 4개에서 505.73초 걸렸다. 첫 120초에서 기존 익명 화자와 새 익명 화자를 시간 겹침만으로 대응했다. 대상 화자는 기존 구간의 99.953%, 새 구간의 99.970%가 일치했고 다른 화자는 양쪽 100% 일치했다. 대응 조건은 결과를 보기 전에 양방향 80% 이상·서로 유일한 최적 대응으로 고정했다.

120초 이후 대상 화자 단독 음성은 149.592초 확보됐지만 다른 화자 단독 음성은 여전히 0초였다. 더 긴 대상 기준에 대한 0.68초 후보의 ECAPA 유사도는 **0.1566**으로 고정 기준 0.6보다 크게 낮았다. 비교 화자 부재로 차이는 계산하지 않았고 `null`로 유지했다.

## 다른 모델과 음성 분리 진단

같은 300초에 Sortformer v2.1을 실행해 4개 익명 화자·136개 발화를 얻었다. CPU 4개에서 8.71초 걸렸다. 120초 이후 길이 기준을 만족한 단독 음성은 `speaker_0` 105.03초, `speaker_3` 1.76초였다. 후보 유사도는 각각 **0.1541**, **0.0549**였다. 두 모델의 익명 화자 ID를 같은 사람으로 가정하거나 이 수치를 화자 대응 승인에 사용하지 않았다.

SepFormer WHAMR로 후보 앞뒤 1초의 분석 사본을 두 채널로 분리한 뒤, 각 채널을 별도 Whisper small로 재인식했다. 제안 대사와 정확히 일치한 채널은 0/2개였고 정규화 문자열 유사도는 0.1429와 0이었다. 채널 순열과 화자 신원이 증명되지 않았으므로 분리 결과는 원인 진단에만 사용했다. 원음과 최종 영상은 변경하지 않았다.

따라서 이번 후보는 단순한 비교 화자 기준 부족이나 혼합 음성만으로 실패한 것이 아니다. 더 긴 대상 음성과도 불일치하고, 두 분리 채널의 대사도 제안과 불일치한다. 이전 별도 ASR 불일치도 유지된다. 사후 사람 정답에서 두 단어를 넣으면 오류가 줄었다는 사실로 검증 기준을 낮추지 않았다.

## 두 모델 합의 음성의 ASR 빈 구간

기존 한 후보에 한정하지 않고 새 누락 후보군도 정답 없이 찾았다. Community와 Sortformer가 모두 말소리로 본 시간의 교집합에서 기존 ASR 단어 앞뒤 0.1초를 제외하고, 0.5초 이상 남은 구간만 선택했다. 3개·총 1.963초가 남았다. 각 구간에 앞뒤 1초 문맥을 더해 Whisper small을 VAD 없이 다시 실행했지만 새 단어 후보는 **0개**였다.

0.3초로 문턱을 낮추면 더 많은 짧은 구간이 생기지만 이 평가 결과를 보고 기준을 바꾸지 않았다. 이번 결과는 두 화자 모델의 합의가 새로운 대사로 이어지지 않았다는 뜻이며, 실제 무음이나 비언어 소리임을 사람 청취로 확정한 것은 아니다. 실패 구간을 정답 분모에서 빼거나 성공으로 계산하지 않았다.

## 구현과 검증

`verify_extended_anchor.py`는 평가 음원과 확장 음원의 앞부분 동일성, 입력 SHA, 같은 모델 익명 화자의 양방향 시간 대응, 평가 구간 이후 단독 발화만을 검증한다. 대체 모델 기준은 수치만 기록하며 승인에 쓰지 않는다. `probe_separated_gap.py`는 두 분리 채널을 모두 재인식하지만 어느 채널도 화자에게 강제 배정하지 않는다. `probe_consensus_speech_gaps.py`는 두 화자 모델의 공통 음성에서 기존 ASR 단어가 없는 구간만 찾아 추가 후보를 생성한다. 원시 음원·대사·임베딩은 비공개 `extended-anchor-20260920`에만 저장했다.

전체 Python **630통과/7skip**, 분리·화자 대응·합의 빈 구간 회귀를 포함한 관련 검사 15개 통과, 변경 Ruff 통과. 코드 검사는 실제 정확도 향상의 증거가 아니다. 공개 집계와 입력 지문은 [results.json](results.json)에 있다. 유료 호출·게시·운영 기본 변경은 없다.

## 다음 작업

이 후보를 더 밀어붙이는 것은 기대 효과가 낮고, 두 모델 합의 빈 구간의 같은 ASR 재시도도 후보 0개로 끝났다. 다음 단계는 다른 인식 계열을 합의 빈 구간에 제한 적용하거나, 더 긴 실제 대화 개발 표본에서 누락 후보 생성 규칙을 검증하는 것이다. 후보 선정 규칙은 사람 정답을 보지 않고 개발 자료에서 먼저 고정한다. 한국어 완전한 사람 정답과 새 한·일·중·영 실제 대화의 전체 CER·DER·오배정 비회귀 검증은 여전히 남아 있다. PR #37은 초안으로 유지한다.
