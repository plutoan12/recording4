# 화자 배정 정확도 개선: 네 단계 비교

## 채택 기준과 결과

기존 단어 배정 기준(3,069 정답 / 109 오배정 / 1,211 미확인)보다 정답을 늘리면서 오배정을 늘리지 않는 변경만 기본 동작에 반영합니다. 분모는 같은 11조건의 원문 4,389자이며 미확인·복수 화자는 정답으로 계산하지 않습니다. 문장 전체 배정으로 돌아가거나 겹말 검수를 해제하지 않습니다.

| 단계 | 정답 | 오배정 | 미확인·복수 화자 | 판단 |
|---|---:|---:|---:|---|
| 변경 전 단어 배정 | 3,069 | 109 | 1,211 | 비교 기준 |
| 1. 유효한 단어 보존 | 3,767 | 109 | 513 | 채택 |
| 2. 순차 교대와 동시 발화 구분 | 3,767 | 109 | 513 | 점수 유지, 경계 규칙 수정 |
| 3. 분석 사본·음소 정렬 합의 | 3,769 | 112 | 508 | 오배정 증가, 기본 적용 제외 |
| 4. 음성 분리·목소리·대사 검증 | 3,769 | 112 | 508 | 3단계 대비 추가 회복 없음, 기본 적용 제외 |

기본 동작의 정답 비율은 **69.9% → 85.8%**입니다. 이 11조건 안에서의 문자 기준 결과이며 일반 영상의 정확도나 DER이 아닙니다. 원래 문장 통째 배정 방식의 정답 4,045자보다 낮지만 오배정도 344자보다 낮습니다.

## 구현

1. 문구와 시각을 단어별로 검증합니다. 정상 단어를 보존하고 누락·잘못된 시각의 부분만 미확인으로 남깁니다. 원문 문자 분모를 유지하며 단어 안쪽의 부분 문자열을 잘못 연결하지 않습니다. 전체 문구와 문장 시각은 변경하지 않습니다. 부분 정렬 여부와 실제 검수 여부를 구분하고 관리화면에 잘못된 시각은 `시각 미확인`으로 표시합니다.
2. 단어가 서로 다른 화자 구간에 걸려도 실제 동시 발화가 없고 한 화자의 시간 비율이 80% 이상일 때만 배정합니다. 같은 화자 구간의 중복은 합집합으로 계산합니다. 진짜 동시 발화·동률·근거 부족은 계속 복수/미확인입니다. 단위 테스트에서 경계 차이를 확인했지만 기존 11조건에는 점수 변화가 없습니다.
3. 실패 문장이 있는 경우 FFmpeg `afftdn` 분석 사본의 stable-ts 결과와 원음의 WhisperX 음소 정렬을 비교합니다. 같은 원문 위치에 대해 화자와 양끝 시각(차이 0.5초 이하)이 일치할 때만 미확인을 채웁니다. 기존 배정은 바꾸지 않습니다. 0dB 한 조건에서 2자를 회복했지만 50% 겹말+잡음에서 오배정 3자가 늘어 채택하지 않았습니다.
4. SepFormer WHAMR로 분석용 두 음성을 분리하고 ECAPA 목소리와 독립 ASR 문구를 확인하는 실험 경로를 구현했습니다. 긴 음원은 4초 중심 구간+문맥으로 나눠 메모리를 제한하고 깨끗한 비겹말 구간의 목소리와 채널을 대응합니다. 원본 개별 화자 음원이나 정답 라벨은 추론 입력에 사용하지 않습니다. 같은 11조건 검사를 완료했으며 3단계 대비 추가로 채택된 정답이 없었습니다. 이는 해당 모델·분리 방식·검증 문턱의 조합 결과이며 음성 분리 전반이 효과 없다는 뜻은 아닙니다.

3·4단계는 `worker.speaker_recovery`와 검증 CLI의 실험 경로입니다. 운영 Celery 작업에는 연결하지 않아 배포 후 자동 실행되지 않습니다. 신규 유료 API 호출·게시·원음 변경은 없습니다.

## 재현

`scripts/verify_overlap_review.py --directory <원본 4발화 및 expected.json> --fixtures <동일 11조건 WAV와 metrics.json> --output <비공개 결과> --cache <비공개 원시 분석 캐시> --stage 1|2|3|4`

첫 단계는 실제 pyannote 및 stable-ts를 실행하여 캐시를 만들고, 후속 단계는 같은 원시 결과를 사용합니다. WAV SHA를 확인하며 3·4단계의 추가 모델은 실제 실행합니다. 캐시를 다른 대본·모델의 분석에 재사용하면 안 됩니다. 평가 정답은 점수 계산에만 사용합니다. 단계별 숫자 JSON만 공개하고 음원·단어별 원문·로그·캐시는 비공개 runtime에 보관합니다.

- 같은 두 화자의 통제 혼합·백색잡음 표본이며 실제 현장 소음, 새 화자, 한·일·중 언어는 별도 검증이 필요합니다.
- 분리 모델은 영어 기반 WHAMR 데이터에서 학습됐으며 4개 언어 일반 성능을 보장하지 않습니다.
- 근거: [WhisperX](https://github.com/m-bain/whisperX), [stable-ts](https://github.com/jianfch/stable-ts), [SepFormer WHAMR](https://huggingface.co/speechbrain/sepformer-whamr).
