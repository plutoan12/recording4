## DiCoW 연결 실험: 실행 실패

`prepare_overlap_target_manifest.py`에 v2.1의 저장된 캐시 사본을 연결했습니다. 25%/50% 겹말 × 2명 = 기존과 같은 4개 입력이며 화자 구간은 모델 예측입니다. 정답은 익명 화자와 평가 대사를 대응하는 데만 사용하고 마스크를 정답으로 바꾸지 않았습니다. 모델/의존성/음원은 읽기 전용 마운트, 네트워크 없음, INT8/CTC 0/greedy/max200 설정 유지.

첫 디코딩 중 컨테이너 종료 **137**, 완료 예측 **0/4**. 7GiB 제한/Docker VM 약 7.75GiB에서 실행했으므로 메모리 부족 가능성이 있으나, 보존된 로그에 명시적 OOM 증거가 없어 원인 확정은 보류합니다. 결과 없는 실행을 CER 성공이나 정답 회복으로 집계하지 않습니다. 잘라낸 입력/줄인 분모/낮춘 최대 토큰으로 성공 처리하지 않았습니다. 기존 완료한 DiCoW 결과는 보존했습니다. 새 입력 SHA와 실패를 results.json에 남겼으며 재시도는 메모리 계측/별도 자원 조정 후 진행합니다.
