# 대상 화자 ASR의 독립 음성·시각 근거 연결

대상 화자 ASR의 대사 일치는 diarization 마스크에 조건화되므로 화자 신원을 독립적으로 증명하지 못한다. 이번 변경은 기존 검수 후보에 음성 신원과 화면의 활성 화자 근거를 함께 연결하는 입력 계약을 추가했다. **화자 배정은 바꾸지 않으며 실제 정확도 증가도 아직 없다.**

## 적용 조건

단어가 후속 재배정 실험의 후보가 되려면 다음을 모두 만족해야 한다.

1. 대상 화자 ASR의 문구 후보가 정확히 한 명이어야 한다.
2. 근거의 음원 SHA, 단어 글자, 단어 시작·끝, cue/word 위치가 현재 평가 입력과 일치해야 한다.
3. 독립 음성 근거가 기존 기준인 match 0.6 이상, 경쟁 화자 대비 margin 0.15 이상이어야 한다.
4. 독립 시각 근거가 같은 대상 화자를 활성 화자로 확인해야 한다. 현재 계약은 활성 화자 탐지 또는 사람 영상 검수를 구분해 기록하며, 점수 범위와 0.7 후보 문턱을 검사한다. 기계 탐지는 보정 확률 선언과 보정 revision뿐 아니라 호출자가 별도로 전달한 신뢰 조합에 있어야 한다. 현재 등록된 조합은 없어 원시 로그잇·임의 변환값·선언만 있는 값은 `untrusted_visual_calibration`으로 남는다.
5. 모델 근거는 모델 revision, 사람 근거는 검수자 ID와 시간대가 있는 검수 시각을 결과에 보존해야 한다. 음성과 화면을 모두 사람이 확인하면 서로 다른 검수자여야 한다.

조건을 모두 통과해도 `qualified_for_reassignment=true`, `applied=false`로만 저장한다. 기존 `speaker`, 글자, 시각은 그대로이고 `changed_assignments=0`이다. 서로 다른 대상의 독립 근거, 복수 ASR 후보, 약한 목소리 유사도, 불명확한 시각 근거는 검수 사유로 남는다.

## 자동화 연결과 한계

`automate_speaker_review.py --independent-evidence <비공개 JSON>`이 기존 품질 판정과 같은 실행에서 근거를 연결한다. 공개 요약에는 조건별 자격 단어 수만 남기며 원시 얼굴·음성·대사는 저장하지 않는다. 오래된 음원이나 다른 단어에 만든 근거를 재사용할 수 없게 입력 SHA와 단어 시각을 다시 확인한다. 요약은 근거 검사를 실행하지 않은 `absent`와 실행했지만 통과가 없는 `evaluated`를 구분하며, JSON `null`이나 객체를 근거 목록으로 받지 않는다. 대상 ASR 제안이 없는 단어의 근거를 조용히 버리지 않고 입력 전체를 거부한다. 재검사에서는 이전 출처를 먼저 지워 현재 실행의 근거만 남긴다.

실제 영상에서 Light-ASD와 Sortformer의 불일치를 계측했지만 사람별 발화 정답이 없어 자격 단어의 정확도 실측은 만들지 않았다. 0.7 시각 문턱도 운영 승인 기준이 아니라 후속 개발 표본을 위한 보수적 후보 기준이다. [실제 영상 진단](../active-speaker-youtube-2026-09-20/REPORT.md)에서 확인한 Light-ASD 출력은 원시 로그잇이라 보정 전에는 이 계약에 넣지 않는다. 다음 단계는 같은 영상의 사람 정답을 만든 뒤, 기존 11조건과 새 한·일·중·영 표본에서 정답 증가·오배정 비증가를 확인하는 것이다. 이 검증 전에는 자동 재배정과 운영 기본 연결을 하지 않는다.
