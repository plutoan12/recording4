# 3단계: 누락 후보 구간의 국소 재인식

원문 대사를 입력받지 않는 국소 재인식 실험과 전체 구간 문자 채점을 구현하고 실제 영어120초에서 실행했다. **운영 채택은 보류**한다. 오류율이 소폭 줄었지만 치환 오류가 늘었고 대상 구간이 매우 좁다. 짧은 맞장구 전체의 검출률이나 네 언어 개선을 입증한 실험이 아니다.

## 실행 전에 고정한 방법

기존 Community가 발화를 찾지 못하고 Sortformer만 발화를 예측한 시각의 합집합을 재시도 핵심 구간으로 삼았다. 정답/대사를 구간 선택에 사용하지 않았다. 핵심 구간에 앞뒤1초를 더하고 겹치는 크롭은 합친다. 같은 Whisper small CPU int8/beam5를 사용하고, 전체 기준 인식은 VAD를 켜며 크롭 재인식은 VAD를 꺼서 재차 발화를 제외하지 않도록 했다. 두 설정의 복합 후보이며 문맥 추가만의 효과를 분리한 것은 아니다.

핵심 구간 안에 중심 시각이 있는 단어만 교체한다. 문맥을 위해 추가한 부분의 단어는 원래 결과를 유지해 중복 삽입을 막는다. 화자 배정은 하지 않는다. 길이0/잘못된 시각의 기존 단어는 원문을 보존하며, 재시도 크롭의 단어 시각에 문제가 있으면 해당 크롭의 교체를 거부하고 실패를 별도로 남긴다.

## 실제 결과

- 영어 AMI 고정120초, 기존 음원·사람 전사SHA 일치 확인.
- 핵심 구간 합계 **0.335781초**, 앞뒤 문맥 포함 **11크롭**. 기준 인식142단어→후보143단어.
- 사람 전사191단어를 NFC/대소문자 통일/공백·문장부호 제거 후 **784자**로 고정했다. 이전 oracle 화자 지표801자와 다른 신규 지표이며 두 분모를 비교하지 않는다.120초를 넘는 부분 단어도 삭제하지 않았다.

| 전체120초 지표 | 기준 | 후보 |
|---|---:|---:|
| 문자 오류율 CER | 21.8112% | 21.6837% |
| 일치 글자 | 616 | 617 |
| 치환 오류 | 10 | 14 |
| 삭제 오류 | 158 | 153 |
| 삽입 오류 | 3 | 3 |

전체 편집 오류171→170으로 **1개 감소**다. 삭제 오류 감소를 정확히5글자의 실제 발화 복구라고 해석하지 않는다. 편집 정렬이 달라져 치환·삭제 항목 사이에 이동할 수 있다. 삽입 수가 같아도 모든 새 단어가 정확하거나 환각이 없다고 증명되지 않는다. 시간순으로 합친 전체 CER이며 겹말/화자별 순서를 처리하는 speaker-aware CER이 아니다.

최종 실행의 크롭 실패0, 기준 인식의 잘못된 단어 시각1개는 원문 그대로 보존했다. 초기 두 실행은 시각 처리 오류로 종료해 성공 결과에 포함하지 않았다. SDK 숫자를 Python float로 변환하고 불확실 시각을 보존하도록 수정 후 같은 입력으로 완료했다. 원음/정답/선정 방법을 변경하지 않았다.

## 해석과 다음 단계

두 화자 모델의 발화 유무 차이는 이 자료에서0.34초뿐이라 기준 ASR의 큰 누락을 대부분 포착하지 못한다. ASR이 빠뜨린 발화와 화자 모델이 빠뜨린 발화는 다르다. 따라서 이 선택 방식만으로 누락 복구를 완료했다고 볼 수 없다. 이후 후보는 ASR 결과의 빈 구간과 음성 활동 근거를 연결해야 하며, 이미 확인한 이 자료는 개발 진단으로 유지하고 새 표본으로 따로 검증한다.

다음4단계 국소 DiCoW에서도 대사 유사도만으로 화자를 자동 수정하지 않는다.2단계 기준 목소리 실패와5단계 한국어 사람 정답/새네언어 전체 평가도 미해결이다.
