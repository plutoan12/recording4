# 소음·겹말 및 실제 더빙 출력 검증

## 범위와 방법

기존 LibriSpeech clean/test 두 화자 6930·1320의 네 문장 원본을 사용합니다. 파일 대응은 a0=`6930-75918-0000`, a1=`6930-75918-0001`, b0=`1320-122617-0022`, b1=`1320-122617-0023`입니다. 순서는 A/B/A/B, 입력은 16 kHz 모노입니다. 각 조각 RMS를 0.08로 맞춘 뒤 섞으며, 최종 피크가 0.95를 넘으면 전체 신호에 같은 배율을 적용합니다. 원본 파일은 수정하지 않습니다.

- 깨끗한 기준 1조건, 백색잡음 명목 SNR 20/10/0 dB × 난수 시드 17/29의 6조건.
- 인접 조각 중 짧은 조각 길이의 25%/50%를 겹치는 2조건과 각각 백색잡음 10 dB를 더한 2조건.
- 총 11조건. 실제 자연 대화나 현장 소음 녹음이 아니라 사람 음성으로 만든 통제된 혼합입니다. 기존 네 문장의 재사용이므로 새 화자·언어 일반화 검증이 아닙니다.
- 운영 `worker.analysis.diarize` 경로, pyannote community-1, CPU. 화자 수 힌트를 주지 않습니다. 유료 API 호출 없음.

화자 수와 문장별 화자 일치율은 따로 기록합니다. 겹말 기준은 섞기 전 두 음성의 20ms RMS가 각각 0.008을 넘는 프레임입니다. 이 에너지 기준은 수동 음성 활동 주석이 아니며 **표준 DER이나 사람 주석 기반 겹말 정확도가 아닙니다**. 겹말 재현율은 이 기준에서 두 화자 이상을 반환한 비율, 과검출 시간은 기준 겹말 밖에서 두 화자 이상을 반환한 시간입니다. 문장별 단일 화자 배정은 겹말의 모든 단어를 각각 전사했다는 뜻이 아닙니다.

## 실제 더빙 출력

새 유료 생성을 하지 않고 기존 6초 영어 더빙 결과를 검사했습니다.

- 전체 디코딩 성공, 디코딩 음성 6.016초(AAC 패딩 포함), NaN/무한값 없음.
- 절대 진폭 1 이상인 샘플 0개. 샘플 피크 -4.95 dBFS, true peak -4.83 dBTP, 통합 음량 -23.98 LUFS.
- 10ms 프레임 RMS -50 dBFS 이하이면서 200ms 이상인 구간: 3.62–6.01초, 약 2.39초. 발화 뒤 무음이며 이 수치만으로 발음·자연스러움 또는 청취상 끊김을 판정하지 않습니다.
- 이전 Whisper 역전사는 영어 번역 대본과 일치했습니다. 역전사 성공은 청취 품질 통과가 아닙니다.

**실제 주관적 청취는 수행하지 못했습니다.** 추출한 WAV를 오디오 입력으로 전달했으나 현재 도구가 `audio input` 미지원으로 거부했습니다. 따라서 발음, 억양, 금속성 음색, 자연스러움은 평가하지 않았습니다. 로컬 재생용 파일 `.runtime/paid-quality-20260920-final.mp4`를 준비하고 Codex 파일 패널 열기를 요청했습니다. 개인 영상·음성은 GitHub에 올리지 않습니다.

## 재현

`python scripts/measure_diarization_stress.py --directory <네 원본 mono-*.wav 폴더> --output <비공개 결과 폴더>`

토큰은 기존 `R4_HF_TOKEN` 환경 설정을 사용합니다. `mono-a0.wav`, `mono-b0.wav`, `mono-a1.wav`, `mono-b1.wav`가 필요합니다. 결과 WAV와 원시 로그는 커밋하지 않습니다. 지표 단위 테스트는 실제 두 화자 겹말과 겹말을 놓친 결과를 구분하고, 한 화자로 뭉친 경우에도 문장 정답을 과대 계산하지 않는지 확인합니다.
