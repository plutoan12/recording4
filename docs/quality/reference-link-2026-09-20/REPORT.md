# 실제 영어 전사 연결과 한국어 검수 준비

운영 모델/기준은 그대로다. 영어는 사람 단어 전사를 기존 화자 시각과 연결했고, 한국어는 실제 음원/부분 전사와 자동 전사 초안을 검수용으로 준비했다. 한국어 사람 정답과 네 언어 전체 평가 완료를 뜻하지 않는다.

## 영어: 같은 회의임을 검증한 사람 전사

[AMI 공식 manual v1.6.2](https://groups.inf.ed.ac.uk/ami/download/)와 [배포에 사용된 diarization setup](https://github.com/pyannote/AMI-diarization-setup)을 받았다. 이전 ihm/test row1이 `TS3003a`의 only_words RTTM과 **전체242구간·화자 ID까지 모두 일치**했다. 부동소수 표현 차이는 소수6자리 정규화로만 처리하며 다른 회의를 파일명 추측으로 연결하지 않았다. 제공자 meetings.xml의 agent↔global_name 매핑을 사용했다.

`link_ami_words.py`는 전체 row/RTTM, 화자 메타데이터, 0–120초 단어의 합집합 발화 구간까지 모두 맞아야 전사를 연결한다. 결과를 기존 pilot lock의 audio SHA와 묶는다. 원음/시각/분모를 다시 선택하지 않았다. 저작권은 기존 CC BY4.0을 따르며 음원·XML·대사·개인 프로필은 커밋하지 않았다.

- 고정120초에 사람 단어 **191개, 공백 제외801자**가 있다. 별도 문장부호 토큰은 어휘 점수에서 제외한다(이 신규 지표의 정의이며 기존 11조건 분모와 비교하지 않는다).
- 단어1개가120초 경계를 넘는다. 끝을120.3초로 늘리거나 단어를 빼지 않는다. 원래 끝시각과 boundary_clipped를 저장하고 해당2자는 모든 후보에서 미확인으로 유지한다.
- 영어 대사 미확보 문제는 해결했다. 경계 부분 단어와 정규화 정책을 포함하는 ASR/CER 연결은 별도 과제다.

## 사람이 준 단어/시각으로 화자 배정만 분리 측정

`score_manual_word_speakers.py`는 기존 stage2 화자 배정과 DER의 익명 화자 최적 대응을 사용한다. 사람이 준 단어/시각이 입력인 **oracle 진단**이며 전체 자동 STT 정확도가 아니다. 같은 저장 예측을 재사용해 모델을 다시 돌리지 않았다.

| 원음 예측 | 정답 | 오배정 | 미확인 | 합계 |
|---|---:|---:|---:|---:|
| Community-1 | 695 | 32 | 74 | 801 |
| Sortformer v2.1 | 715 | 32 | 54 | 801 |

이 숫자만으로 후보를 채택하면 안 된다. 현재 단일 화자 배정은 단어와 조금만 겹쳐도 전체 단어에 붙는다. 진단을 추가한 결과 단어 시각의80% 미만만 같은 예측 화자가 덮는 정답 글자가 기존49자/후보187자였다. 기존의 오배정11자도 이런 약한 근거 배정이다. 후보가 단어 점수는 높으면서 시간 DER은 악화하는 이유를 설명하는 하나의 요인이다.

80%는 기존 stage2 순차 경계의 강한 다수 기준을 진단에 재사용했다. 주 점수/기존 배정을 바꾸거나 후보에 맞춰 문턱을 튜닝하지 않았다. 중복 트랙으로 지지 시간이 부풀지 않도록 구간 합집합을 쓴다. 이 추가 수치를 새 운영 승인 기준이나 독립 목소리 증거로 취급하지 않는다.

## 한국어: 실제 음원과 검수해야 할 부분을 구체화

[OpenSLR113 서울 코퍼스](https://www.openslr.org/113/)의 공식 설명서/주석/음원을 확보했다. CC BY-NC2.0 연구용이다. ZIP의 Apple resource fork를 제외한 첫 실제 TextGrid와 같은 음원 `s01m16f1`의 처음120초를 고정했다. 배포 FLAC은22050Hz mono로, 원본 보존 후16000Hz 사본을 만들었다. 문서의 원래 녹음 주파수44kHz를 배포 파일의 실제 값으로 오인하지 않았다.

제공자 utterance 주석86구간 중 일반 참여자 전사37, 질문자 대사를 `<IVER>`로만 표시한22, 잡음/웃음/불명확 등 특수표기27구간이 있다. 질문자 전사와 완전한 겹말 주석은 제공되지 않는다. `<IVER>`를 대사로 넣거나 자동 모델의 화자를 사람 정답으로 대체하지 않았다.

캐시된 Whisper small로 같은120초의 **자동 전사 초안24구간**을 네트워크 차단 컨테이너에서 만들었다. `human_annotated=false`, `evaluation_truth=false`로 저장하고 정답과 분리했다. `REVIEW.html`에서 원음을 구간별 재생하며 제공자 주석과 초안을 나란히 볼 수 있다. 이 화면은 사람 검수를 돕는 비공개 읽기용 자료이며 승인/평가 준비 완료를 자동으로 설정하지 않는다.
