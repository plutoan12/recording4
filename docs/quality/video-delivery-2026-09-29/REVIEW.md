# 실제 제작본의 자막·모자이크 후속 검수

한국어 원본 32.6초 한 편의 검수다. 네 언어 정확도나 화자 정확도 개선을 측정한 평가가 아니다. 원시 영상·음성·대사·모델 가중치는 비공개 로컬 폴더에 보관한다.

## 결과와 한계

- 기존 초안에 추가한 두 로컬 ASR의 일치 제안으로 자막 네 곳에 수정 후보를 반영했다. 같은 Whisper 계열이므로 합의가 정답을 증명하지 않는다. 시작 단어·말실수 표현·마지막 겹말의 세 구간은 결과가 충돌해 사람 청취 대상으로 남겼다. 한 모델이 마지막 응답을 누락했으며 그 결과로 전체 대본을 교체하지 않았다.
- 짧은 자막 한 곳을 0.72초에서 1초로 늘렸다. 같은 규칙으로 실제 SRT를 검사해 가독성 경고가 **1개에서0개**로 줄었다. 원본9개 대사 구간은 유지하며 표시용 자막은11개에서10개가 됐다. 이는 가독성 검사이며 CER·대사 정확도·음성 경계 오차 개선 수치가 아니다.
- 새 자동 모자이크본의 0.5초 간격 **66프레임**과 이전 결과와 차이가 큰8프레임을 시각 확인했다. **29.5초에서 손에 일부 가려진 얼굴이 누락됐다.** 이전 민감도 검수본에도 같은 누락이 있다. 초기 비공개 기록의 ‘보이는 주요 얼굴 모두 가림’ 관찰을 정정했다. 큰 영상 차이는 확인한8프레임에서 배경/몸의 과도 가림 차이였고 정확한 발생 원인은 이번에 확정하지 않았다.
- 별도 로컬 보완본에 **28.8–30.6초**, `x=0, y=468, width=720, height=342`의 영역 모자이크(24×12격자)를 추가했다. 구간과 앞뒤 경계의 연속60프레임(862~921) 및 다른3프레임을 확인해 발견한 누락을 가렸다. 손·배경도 함께 가린다. 모든976프레임의 얼굴 누락/과도 가림을 검수한 것은 아니며 완전한 비식별화를 보장하지 않는다.
- 자동 렌더본과 보완본 모두 전체 오디오·영상 디코딩 통과, **976프레임·30fps·720×1280** 유지. 보완본의 오디오 PCM은 기존 검수본과 바이트 단위로 같다. 실제 음질 청취 완료로 해석하지 않는다.

## 다운로드 자막 불일치와 코드 수정

기존 API 자막의 한 문장 경계는17.199초, 실제 구운 자막은16.970초였다. API는 선택 의존성 KSS가 없는 환경에서 자막을 다시 나눴다. 같은 표시 규칙이어도 워커가 만든 문장/시각과 달라졌다. 16.9·17.0·17.2·17.3초 영상 표시를 대조하고 같은 워커/저장 설정의 ASS에서 로컬 보완 SRT/VTT를 생성했다. API에서 처음 받은 파일도 보존한다.

후속 코드는 편집본 렌더에서 확정한 SRT/VTT를 작업 결과에 저장해 API가 재계산 없이 내보낸다. 구운 자막은 ASS 저장 후 실제 0.01초 시각을 읽고, 자막 트랙만 쓰는 경우는 워커의 문장 분할/시각을 고정한다. 화면 제목은 제외한다. 저장된 파일이 손상됐으면 실패하며 이전 결과물에는 자동으로 확정 기록을 만들어 넣지 않는다. 번역·더빙 작업의 기존 계산 경로는 범위 밖이다.

- KSS 유무 전환, 구운/트랙 전용 자막, 손상된 저장 파일 **5개 회귀가 수정 전 실패·수정 후 통과**했다. 렌더 자막 생성·작업 결과 저장·HTTP 다운로드를 함께 검사하며 FFmpeg 실행과 저장소만 대역이다.
- 의존성이 있는 로컬 격리 이미지의 전체 Python **628통과/2skip**. 실제 FFmpeg 렌더/디코딩 검사를 포함한다. SQLite에서 PostgreSQL 행 잠금·세션 시간대 검사는 제외됐다. 서드파티 deprecation/pecab overflow 경고8개는 남았다.
- 첫 경량 개발 이미지 검사는 numpy 부재로 sync matrix4개가 실행 오류였으며, 의존성이 있는 환경의 전체 실행으로 해소했다. 애플리케이션 오류를 누락하거나 검사 기준을 바꾸지 않았다.
- Ruff0.8.4와 포맷 검사 통과. GitHub CI·main 병합·운영 반영은 HANDOFF의 최신 상태를 따른다. 제작 워커의 얼굴 검출 기본값과 운영 STT 모델은 바꾸지 않았다.
- PR #41 검토 후 문자열 내용이 깨진 SRT/VTT도 검사하도록 보완했다. 새5조건은 수정 전 HTTP200으로 잘못 통과했고, 수정 후 양쪽 형식 다운로드에서409로 거부된다. 형식별 파싱·비어 있지 않은 글자·유효한 시작/끝을 확인하되 내려주는 원본 문자열은 변경하지 않는다. 최종 로컬 편집 API31개, 전체 **633통과/2skip**, Ruff/포맷 통과다. 실제 영상이나 모델은 다시 생성하지 않았다.

## 로컬 모델과 실행 범위

공개 가중치 다운로드 후 기존 워커 이미지의 CPU4/int8, 한국어 지정, beam5, VAD·단어 시각 사용으로 처리했다. 영상·음성을 외부 인식 서비스에 전송하지 않았다. 다음은 동일 계열 후보 비교이며 독립 정답이나 검증된 모델 추천이 아니다.
