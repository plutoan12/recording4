# FireRedVAD 독립 음성활동 다국어 실험

경계 복구 후보가 실제 무발화 구간에서 생긴 원인을 줄이기 위해 [FireRedVAD](https://github.com/FireRedTeam/FireRedVAD)를 운영 밖에서 실험했다. 소스 commit `c30ec49e8cc69642b0ee65362eba11b9d11c6e54`, [Hugging Face 모델](https://huggingface.co/FireRedTeam/FireRedVAD) revision `7990aaccc6b7aec1e527743bd30201f2c4a03b8c`와 기본 VAD 설정을 고정했다. 소스는 Apache-2.0이며 모델·원음·프레임 확률은 비공개 `fireredvad-eval-20260920`에만 저장했다.

## 독립 영어 오검출

앞선 독립 AMI 개발 회의의 47.46~48.34초 공통 오검출에서 FireRedVAD 최대 음성 확률은 **0.0253**으로 기본 문턱 0.4보다 낮았다. 다음 50.13~50.55초의 짧은 공식 발화는 **0.4628**이었다. 해당 사례에서는 Silero와 Whisper 신뢰도보다 잘 분리했다. 이 결과를 본 뒤 문턱을 바꾸지 않았으며 공식 시각은 추론 뒤 진단에만 사용했다.

## 고정 세 언어 비교

기존에 고정한 중국어 AliMeeting, 일본어 J-CRe3, 영어 AMI 각 120초와 사람 화자 시각을 그대로 사용했다. 화자 수와 ID를 무시하고 한 명 이상 말한 시간의 합집합을 기준으로 collar 0에서 miss와 false alarm을 계산했다. 겹말은 음성 존재 채점에서 한 번만 센다.

| 언어 | 모델 | miss(초) | false alarm(초) | recall | precision |
|---|---|---:|---:|---:|---:|
| 중국어 | FireRed | 6.820 | 2.110 | 93.67% | 97.95% |
| 중국어 | Silero | 0.000 | 5.406 | 100.00% | 95.22% |
| 일본어 | FireRed | 6.329 | 2.876 | 89.25% | 94.81% |
| 일본어 | Silero | 3.857 | 14.258 | 93.45% | 79.41% |
| 영어 | FireRed | 30.610 | 0.270 | 62.43% | 99.47% |
| 영어 | Silero | 7.054 | 2.006 | 91.34% | 97.38% |

FireRed는 오검출이 적지만 영어 개인 헤드셋의 작은 상대 화자 음성을 많이 놓쳤다. 정밀도만 보고 기존 검출기를 바꾸면 실제 대사를 잃는다.

Community 발화 구간에 FireRed 구간을 더하는 합집합도 확인했다. 총 `miss + false alarm`은 일본어 **8.884→8.839초**, 영어 **9.390→9.337초**로 아주 조금 줄었지만 중국어는 **2.612→3.392초**로 늘었다. 각 언어 한 대화뿐이고 한국어 사람 정답이 없으므로 언어별 선택도 채택하지 않았다.

## 구현과 결론

`score_speech_activity.py`는 PCM16 16kHz mono 음원 SHA, 모델 revision, 사람 시각과 예측 파일 SHA, 고정 평가 끝을 연결한다. 겹친 사람 발화는 합쳐 음성 존재 분모로 한 번만 세고, 무효·범위 밖 시각을 자르지 않고 거부하며 기존 출력도 덮어쓰지 않는다. 이는 DER의 화자 혼동 채점과 별개다.

FireRed 모델과 새 의존성은 워커에 설치하지 않았다. 운영 후보 생성·거부·화자 배정은 바뀌지 않았고 유료 호출·게시도 없다. 이 실험은 새 검출기의 정밀도 장점을 확인했지만 세 언어 비회귀와 네 언어 정확도 개선은 입증하지 못했다. 다음 검증은 새 대화 여러 개와 한국어 사람 시각을 먼저 추가한 뒤, 사전에 고정한 합집합 규칙을 같은 분모로 비교해야 한다.

로컬 검증은 Python **680통과/2skip**, Ruff 검사·형식 검사 통과다.
