# 2단계: 대체 모델 구간의 실제 음성 기준 후보 검사

Community-1에서 기준 목소리가0초인50% 겹말 조건을 대상으로 Sortformer의 단독 발화 예측을 확인했다. 대상 후보가 두 조건 각각3.84초 존재해 실제 ECAPA 음성 임베딩으로 확인했다. 결과가 부족해 화자 재배정/운영 복구에 연결하지 않았다.

## 구현과 실험

`probe_voice_anchors.py`는 정답/대사/분리된 원본 목소리를 입력받지 않는다. 음원SHA가 맞는 저장 예측에서 동일 화자 구간을 합치고 다른 화자와 겹친 시각을 제거한다.0.5초 이상 남는 구간을 모으고 총1초 이상일 때 서로 겹치지 않는 두 절반으로 나눠 목소리 일관성을 계산한다. 다른 예측 화자의 두 절반과도 비교한다.

기존 복구 기준인 코사인 유사도0.6/경쟁 화자 대비 차이0.15를 실험 전에 재사용했다. 이 절반 구간 검사에 따로 보정된 기준이라는 뜻은 아니다. 통과는 `candidate_only`이며 동일 화자 실제 정답, 음성 순도, 원래 Community ID와의 대응을 승인하지 않는다. 짧은 발화의 발음 차이·잡음 등도 유사도를 낮출 수 있어 낮은 점수를 다른 사람이거나 오염된 목소리라는 증거로 단정하지 않는다.

네트워크 차단/CPU2개/메모리4GiB의 별도 컨테이너에서 캐시된 `speechbrain/spkrec-ecapa-voxceleb`만 사용했다. 모델 캐시는 읽기 전용이고 운영 시크릿은 연결하지 않았다. 모델 snapshot `0f99f2d0ebe89ac095bcc5903c4dd8f72b367286`, 설정SHA와 음원/예측SHA는 results.json에 보존했다. 익명 화자 ID/공개 집계만 저장하며 원시 음원과 임베딩은 GitHub에 넣지 않았다.

## 실제 결과

기존11조건 전체를 검사했다. 원음/화자 예측은 기존과 같으며 새로 실행한 것은 임베딩 계산이다. 화자 분리 모델을 재추론하거나 자막 정확도를 재채점한 것은 아니다.

- 깨끗한 조건, 잡음6조건,25% 겹말2조건: 두 화자 모두 후보 기준 통과(9조건).
-50% 겹말: 짧은 후보3.84초의 절반 간 유사도 **0.5911**, 다른 화자 최대0.1679, 차이0.4231. 일관성 기준 미달.
-50% 겹말+잡음: 같은3.84초 후보 유사도 **0.4729**, 다른 화자 최대0.0731, 차이0.3998. 일관성 기준 미달.

즉 기준 구간 부재를 대체 예측으로 보완할 후보는 발견했으나, 가장 필요한 두 조건은 검사에 통과하지 못했다. **9/11은 자막 정답률이나 화자 복구 성공률이 아니다.** 임계값을 낮추거나 통과한 조건만 남기지 않았다. 두 후보에 따른 자동 배정 변경0자, 새 정답 회복0자.

## 검증/다음 작업

구간 중복, 실제 겹말 제거, 다른 화자와 너무 비슷한 후보 거부, 입력 시각 오류를 테스트했다. Python603통과/7skip, 신규 Ruff 통과. 기존 모델과 주 품질 점수는 바뀌지 않아 DER·11조건 자막 재채점은 반복하지 않았다.
