# 단기 GPU 실험 준비

사용자 요청: Mac 실행 자원 문제를 피하기 위해 단기 GPU 대여로 같은 실험을 완료한다. **서버 생성/결제/업로드/실제 CUDA 추론은 아직 하지 않았다.** Mac 잠금 때문에 계정 화면에 접근하지 못했고 새 비용 승인이 필요하다.

## 제안 구성과 비용

- Runpod RTX 4090 24GB VRAM, 호스트 RAM 32GB 이상, 단일 단기 Pod. 장기 계약/자동 충전 없이 시작한다.
- 공식 모델 페이지 상단 가격은 시간당 $0.74부터이지만 같은 페이지 본문에는 $0.34도 있어 실시간 견적을 확정 가격으로 사용해야 한다. 저장소 요금도 별도다.
- 공식 결제 문서는 선불 $10부터 시작 가능하며 충전액 환불 불가라고 명시한다. 기존 월 총예산 $10/ElevenLabs $6 승인과는 별도 승인이 필요하다. 결제하지 않았다.
- 실행 사용료 목표 $2 이내 제안. 실제 견적·저장소·종료 제어를 확인하기 전에는 이 한도가 구현됐다고 표현하지 않는다. 프로세스 종료만으로 서버 과금이 종료되지 않는다.
- https://www.runpod.io/gpu-models/rtx-4090
- https://docs.runpod.io/accounts-billing/billing

## 준비한 실행 코드

`benchmark_target_asr.py --device cuda`는 모델과 입력 텐서를 CUDA로 이동한다. GPU가 없거나 CPU 동적 INT8를 동시에 요청하면 실패한다. 묵시적 CPU 대체를 하지 않는다. 기본 CPU 경로와 기존 결과 지문은 유지하며 CUDA 결과는 별도 지문/장치/정밀도로 기록한다.

`run_dicow_benchmark.py --device cuda`는 Docker GPU 접근과 24GiB 호스트 RAM 한도를 요청한다. 실제 GPU 호스트에는 CUDA 지원 PyTorch 이미지가 필요하다. 현재 Mac의 CPU 워커 이미지를 GPU 지원 이미지라고 취급하지 않는다. 모델/스크립트/음원은 읽기 전용, 결과 폴더만 쓰기 가능, 추론 컨테이너 네트워크 없음.

## 비교 순서

1. 가입/로그인, 실제 대여 견적과 충전/총지출 승인 확인. 서버 생성 전 종료·결과 회수 절차와 제어 경로 준비.
2. 고정 DiCoW 체크포인트/의존성, 공개 평가 음원의 비공개 사본, 필요한 실행 코드만 전송. production.env/YouTube/API/HF 비밀 파일은 전송하지 않음.
3. CUDA float32에서 기존 Community-1 마스크 4개와 Sortformer v2.1 마스크 4개를 모두 실행. 이전 CPU INT8 결과와 장치/정밀도가 달라 GPU에서 기준도 함께 실행해야 비교 가능.
4. 동일 음원 SHA/정답/25%·50% 조건/분모/CTC0/greedy/max200 유지. 실패도 기록하며 완료된 일부만 전체 개선으로 합산하지 않음.
5. 결과를 Mac으로 회수하고 서버 과금 종료를 제공자 상태로 확인. 네 언어 실제 대화 미완료와 운영 승인 보류는 유지.

현재 검증은 로컬 장치 검증·결과 재사용 방지 회귀이며 실제 CUDA 모델 실행 검증을 대신하지 않는다.
