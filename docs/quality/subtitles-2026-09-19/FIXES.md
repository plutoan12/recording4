# 품질 개선과 재검증

## 반영한 수정

- 숫자·금액·시각과 일부 일본어 어미를 보호해 줄/자막 분할 시 중간을 자르지 않습니다. `12美元`, `2 AM`, `から`의 실제 이전 실패 화면을 회귀 사례로 사용합니다. 한 토큰 자체가 한 줄보다 긴 경우는 폭 제한을 유지하기 위해 분할될 수 있습니다.
- 한국어 `녹화` 또는 일본어 `録画`가 명시되고 같은 문장에 `녹음`/`録音`이 없는 경우에만 중국어 번역의 `录音`을 `录像`으로 보정합니다. 모호한 영어 recording, 원문 언어 자동 감지(None), 영상·음성 혼합 문장에는 적용하지 않습니다. 일반적인 번역 품질이나 문체 통일을 해결하는 모델 변경은 아닙니다.
- Claude PR #23의 SyncOptions·워크플로 연결·방어 테스트를 가져왔습니다. 프레임률 변경을 끄고 최대 이동 10초로 제한하며, 음수 시각/개수 변경을 거부합니다. 비유한 상한·오프셋과 결과의 한도 초과 검사도 추가했습니다. PR #23 전체 또는 CI/화면 수정은 병합하지 않았으므로 추후 중복을 정리해야 합니다.

## 검증

- 전체 테스트 **382개 통과, 5개 조건부 skip**. Ruff 통과.
- 기존 한국어 사람 목소리 34.178초·3문장 표본: +2.5초 입력에 -2.800초 보정, 최대 시작 오차 **0.300초**. 이미 맞는 입력에는 -0.300초 보정, 최대 흔들림 **0.300초**. 기존 0.5초 기준 둘 다 통과했습니다. 이전 검사에서 최대 자막 길이 설정까지 바꾼 실험과 다르게 이번에는 PR #23의 기본 옵션만 사용했습니다.
- 이 측정은 ffsubsync 결과입니다. stable-ts 대체 경로를 추가하지 않았습니다. 표본 하나가 통과한 것이며 다른 언어·긴 영상·배경음에서의 정확도를 보장하지 않습니다.
- 한국어→중국어, 일본어→중국어 실제 번역을 재실행해 `录像` 결과 확인. 원래 시간 유지, 영상 생성·검수 대기까지 완료. 추가 내부 비용 **$0.0040**, 게시 없음. [실제 결과](fixed-terms.json)
- 기존 네 언어 번역으로 실제 영상을 다시 렌더링했습니다. [중국어 숫자](en-zh-fixed.png), [일본어 어미](en-ja-fixed.png), [영어 시각](ko-en-fixed.png)의 분리 문제가 사라진 것을 화면에서 확인했습니다.

## 남은 범위

일본어·중국어의 모든 형태소/의미 단위 줄바꿈, 전체 문체 통일, 모호하거나 혼합된 녹음/녹화 문장, 다양한 실제 영상의 싱크 품질은 여전히 검수가 필요합니다. 기존 결과물·승인은 바꾸지 않았으며 수정 규칙은 새로 생성하는 결과물부터 적용됩니다.
