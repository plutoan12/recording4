## 실제 검증 결과

- Google 번역을 실제 호출: ko/en/ja/zh 간 **12방향 × 4문장 = 48문장**. 업데이트 중 전원 차단 금지, 내일 오전 2시, 10→12달러 변경, 저장 후 3초 대기, 녹화 지속 문장을 사용했습니다.
- 모든 작업이 `transcribe → translate:0 → render → review_required`까지 완료. 더빙·립싱크·YouTube 업로드·공개 승인 없음.
- 48개 번역 구간의 시작·끝은 입력과 동일. 문장 수 누락 없음. 부정·가격·시각·순서의 핵심 의미는 표본에서 유지됐습니다.
- 12개 작업 모두 SRT/VTT 내보내기와 재파싱 성공. 설정된 줄 수·읽기 속도·기간·겹침 검사 경고 0개. **이는 숫자/어구 분리와 번역 의미까지 통과했다는 뜻이 아닙니다.**
- 12개 실제 영상의 전체 오디오·비디오 디코딩 성공. 원본과 출력의 16kHz 모노 PCM 상관계수는 모두 약 **0.999988**, 오디오 길이 차이 **0초**. AAC 재인코딩을 거치므로 비트 단위 동일성 검사는 아닙니다.
- 네 언어의 대표 프레임을 직접 확인: 글리프 누락·화면 밖 잘림 없음. 위 줄바꿈 문제는 확인됨.

## 사람 목소리 정렬

기존 공개 Bingsu/zeroth-korean 표본 3문장을 연결한 34.178초 자료로 두 기능을 비교했습니다. 오디오·원문 자료는 저장소에 다시 올리지 않고 측정값만 저장합니다.

- `stable-ts`/Whisper small: 원문 글자 유지, 구간 겹침 없음. 문장별 시작 오차 **0.773 / 0.077 / 0.065초**. 기존 시작 오차 1초 기준 통과. 첫 문장은 약 0.77초 늦게 뜨므로 정밀 싱크가 완성됐다는 뜻은 아닙니다.
- 표본 기준 끝 시각보다 첫/마지막 문장의 끝이 각각 약 **1.41 / 1.74초 빠름**. 표본의 끝 경계에는 무음·잔향이 포함될 수 있어 이 수치만으로 잘못된 말끝이라고 단정하지 않았으며, 문장 끝의 청취 기반 정답 검증은 남아 있습니다.
- `ffsubsync`: +2.5초 이동, 이미 맞는 자막 두 경우 모두 실패. 운영 대본은 건드리지 않은 독립 측정이며, 실패 결과를 성공으로 저장하지 않았습니다.
