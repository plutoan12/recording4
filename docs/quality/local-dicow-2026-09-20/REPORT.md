# 4단계: 실제 영어 겹말 의심 구간의 국소 DiCoW 비교

사람 단어/시각이 있는 고정 영어 AMI120초에서 두 화자 모델의 겹말 불일치로 정한6구간을 재인식했다. **30개 디코딩 모두 정상 종료했으나 운영 채택은 보류**한다. 이번 비교는 같은 DiCoW에 Community/Sortformer 예측을 넣는 비교이며 기존 Whisper ASR와의 직접 비교는 아니다.

## 사전 고정 방법

- 기존 `compare_turns`/`overlap_retry_windows`의 앞뒤0.5초 문맥 규칙을 그대로 사용했다. 정답은 구간 선택에 쓰지 않았다.
-6구간은 약1.01~1.61초다. 원문 단어가 경계에 걸쳐도 전체 글자를 분모에 남겼다. 같은 구간/정답을 양쪽에서 사용한다. 잘린 단어11개가 있어 이 국소CER은 보수적인 진단이며 전체 영상/새네언어 정확도가 아니다.
- 예측된 모든 화자를 디코딩했다. 정답을 이용한 익명ID의 최적 대응은 평가용 문자열 연결에만 사용하며 STNO입력은 모델 예측 그대로다. 실제 사람 음성/정답 화자 마스크는 추론에 주지 않았다.
- Community는2화자×6구간=12개, Sortformer는3화자×6구간=18개를 실행했다. 고정4정답화자×6구간×2방법=48평가칸에서 예측 화자가 없으면 빈 출력으로 채점하고 정답 글자는 남겼다. 정답 대사가 없는 화자 출력도 삽입 오류로 포함한다.
- CPU float32/같은 DiCoW checkpoint `00a09c622bf58c34fdc76c3b5676f4da706f2a8e`/CTC0/beam1/최대200토큰. 기존 native 전용 환경을 사용했고 유료 호출이나 운영 설정 변경은 없다.

## 실제 결과

| 지표 | Community 구간 입력 | Sortformer 구간 입력 |
|---|---:|---:|
| 정답 글자 분모 | 115 | 115 |
| 문자 편집 오류 | 75 | 106 |
| 보수적 국소 CER | 65.22% | 92.17% |
| 정답이 빈 화자의 삽입 오류 | 4 | 12 |
| 예측 화자 부재로 남는 정답 글자 | 9 | 9 |
| 경계에 걸친 정답 단어 | 11 | 11 |
| 출력 길이 제한 도달 의심 | 0 | 0 |

각 방법에서6개 구간의 모든 평가칸을 포함했다.30/30은 실행 완료 비율이며 정확도/복구 성공률이 아니다. 빈 정답칸의 CER은 정의하지 않고 삽입 수를 전체 오류에 더한다. 기존 runner의 단일행 `max(1, reference_length)` 비율은 결론에 사용하지 않고 새 scorer로 계산했다. 재인식 결과를 기존 자막에 합치거나 화자를 수정한 수는0이다.

## 해석과 한계

이전25%/50% 통제 겹말 전체 클립의 결과와 달리, 실제 영어의 짧은 국소창에서는 후보 화자 입력이 더 나빴다. 표본/길이/정답분모가 다르므로 이전39.85→1.50%와 직접 개선율을 계산하지 않는다. 문맥 부족과 경계 절단이 원인 후보이나, 이번 실험만으로 인과를 증명한 것은 아니다.

모델 내부 decoder attention-mask 경고가 기록됐다. 기존 runner가 입력 feature attention mask는 전달하지만 이 경고의 영향까지 검증하지 않았으므로 해결됐다고 표현하지 않는다. 이 결과로 기준을 낮추거나 짧은구간 실패를 제거하지 않는다.

다음 개선은 예측 발화 경계에 맞춘 더 긴 문맥/출력 시각 연결을 검증해 문맥 부분 대사를 중복 삽입하지 않는 것이다. 현재30개 결과에는 단어 시각이 없어 핵심 겹말 부분만 안전하게 자동 합칠 수 없다. 독립 음성·시각 확인과 한국어 사람 정답/새네언어 전체평가도 남는다.
