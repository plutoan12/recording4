# 저음량·긴 자막 싱크 보정 개선

## 적용 내용

관리화면의 별도 **자막 싱크 보정** 메뉴에 세 가지 방식을 연결했습니다. 기본값은 기존 `standard`이며 언어를 보고 모드를 자동 선택하지 않습니다.

- **기본 보정**: 기존 계산 방식. 한국어·중국어 기존 표본의 동작을 유지합니다.
- **작은 음량·음량 차이 보정 (`quiet`)**: 임시 오디오에 FFmpeg `dynaudnorm=f=500:g=31:p=0.5:m=10:r=0.05`를 적용합니다. 증폭은 최대 10배이고 원본 파일·최종 영상 소리는 바꾸지 않습니다.
- **긴 문장 자막 보정 (`long_cues`)**: ffsubsync의 기본 10초 분석 길이 제한을 입력의 최대 자막 길이 이상으로 늘립니다. 라이브러리가 정렬 실패를 반환하거나 발화 근거가 부족하면 분석용 음량 보정으로 한 번 재시도합니다. 이미 성공한 값을 더 작은 이동값으로 임의 교체하지 않습니다.

두 새 방식은 일반적인 품질을 항상 보장하는 옵션이 아닙니다. 문장 길이 제한 변경이나 강한 음량 보정을 전역 적용하면 다른 조건이 악화되는 것을 실험에서 확인했으므로 **명시적으로 선택하도록** 했습니다. 길고 짧은 자막을 적절히 나누고, 보정 결과의 앞·중간·끝을 확인해야 합니다.

API는 `POST /source-assets/{id}/transcript/sync?profile=standard|quiet|long_cues`입니다. 같은 진행 중 요청은 기존 작업을 반환하고, 다른 방식이 진행 중이면 409를 반환합니다. 미지정 요청·이전 작업의 기본값도 standard입니다. 선택한 방식은 작업 설정과 결과에 남고 워커까지 전달됩니다.

## 무음 성공 오판 수정

ffsubsync가 무음 WAV에서도 성공을 반환하는 것을 실제로 재현했습니다. 기준 발화 마스크에 유한한 값이 있고 발화/비발화가 각각 0.5초 이상인지 검사합니다. 상수 마스크는 시간 이동을 판단할 정보가 없으므로 중단합니다. 검증한 마스크를 임시 npz로 넘겨 오디오를 중복 분석하지 않습니다.

이 검사는 완전한 신뢰도 판정은 아닙니다. 잡음을 말로 잘못 감지하거나 대본 내용이 다른 경우까지 보증하지 않습니다. 실패 시 원래 대본을 보존하며 새 대본 버전이나 영상 승인을 만들지 않는 회귀 테스트를 추가했습니다.

## 실제 음성 결과

[이전 검사](../multilingual-sync-2026-09-19/REPORT.md)와 같은 소수의 공개 사람 낭독 표본 및 통제 조건을 사용했습니다. FLEURS en/ja/zh 각 3개, 기존 한국어 9개입니다. 출처·리비전·파일 해시는 이전 보고서에 있습니다. 샘플 반복, 속도/음량 변경, 합성 잡음·화음으로 만든 MP4이며 새로운 자연 현장 영상이나 독립적인 미사용 표본 평가가 아닙니다.

각 언어 10조건 × 이동 0/+2.5초 = 20검사. 시작·끝 및 이동값 오차 0.5초 기준과 텍스트/개수 보존 조건을 유지했습니다. 거부는 실패로 셉니다. 기준 발화 경계는 음량 기반 추정이며 수동으로 검증한 음소 경계가 아닙니다.

| 표본 | 이번 선택 방식 | 이전 기본 보정 | 이번 결과 | 남은 실패 |
|---|---|---:|---:|---|
| 영어 | 작은 음량 | 0/20 | **12/20** | 느린 말 2개, 추가 -18dB 2개, 잡음 2개, 음악 2개 |
| 일본어 | 긴 문장 | 0/20 | **18/20** | 추가 -18dB 2개: 음수 시각 방어로 거부 |
| 한국어 | 기본 | 20/20 | **20/20** | 이 표본에서는 없음, 빠른 말 0.50초 경계 |
| 중국어 | 기본 | 20/20 | **20/20** | 이 표본에서는 없음, 최대 0.05초 |

**하나의 기본 설정으로 네 언어가 모두 통과했다는 뜻이 아닙니다.** 실제 화면에서 새 방식을 선택해야 영어·일본어 개선 경로를 사용합니다. 영어에서 받아들인 결과에도 최대 0.70초 오차가 남았고, 일본어는 거부한 2개를 제외한 최대 오차가 0.11초입니다. 완전 자동 품질 보장은 아직 아닙니다.

- `*-final.json`: 최종 코드(무음 방어 포함)로 재실행한 80개 결과.
- `*-quiet-probe.json`: 동일 제한 증폭 방식의 초기 전체 언어 실험. 한국어/중국어 20/20, 영어 12/20, 일본어는 실패. 최종 방식 선택의 근거이며 최종 제품 검사와 구분합니다.
- 강한 증폭(최대 100배), 다른 음량 정규화, Silero 및 발화 경계/중심 비교도 시험했지만 범용 개선을 입증하지 못해 채택하지 않았습니다. 평균 점수나 특정 언어의 통과율만으로 기본값을 바꾸지 않았습니다.

## 검증

- Python **411 통과, 5 조건부 skip**, Ruff·TypeScript·Vite 빌드 통과.
- 입력 음원 SHA-256 불변, 분석용 사본의 길이 차이 0초 확인.
- 실제 무음 WAV를 기본/작은 음량/긴 문장 세 방식 모두 거부. 상수 발화 마스크와 무음 마스크 회귀 테스트 추가.
- API 모드 검증·중복 요청·충돌·워커 전달·새 대본 버전 생성·실패 시 원문 보존 검사.
- Chrome 격리 테스트 앱에서 세 선택지, 기본값, 선택 상태, 설명과 대본이 없을 때의 버튼 비활성화를 실제 화면으로 확인. 이 UI 표본에는 영상 파일이 없어 재생 확인은 포함하지 않았습니다.
- 유료 호출·YouTube 게시 없음.

## 재현과 다음 개선

워커 이미지의 FFmpeg/Python 환경에서 실행합니다.

```sh
python scripts/fetch_fleurs_speech.py --language en --out /tmp/en
python scripts/verify_sync_matrix.py --directory /tmp/en --out /tmp/en-results --profile quiet
python scripts/fetch_fleurs_speech.py --language ja --out /tmp/ja
python scripts/verify_sync_matrix.py --directory /tmp/ja --out /tmp/ja-results --profile long_cues
```

실패 사례가 있으면 종료 코드 1입니다. 아주 작은 음량·잡음·음악의 실패 조건, 수동 발화 경계 기준, 다른 화자/실제 현장 영상 검증이 남아 있습니다. 더 강한 보정을 기본으로 켜거나 허용 오차를 늘려 이 실패를 통과로 처리하지 않습니다.

## 운영 반영 확인

API·워커·디스패처·모니터·웹 이미지 재빌드/재시작 후 전체 서비스 healthy를 확인했습니다. 배포된 API 스키마에서 세 모드와 standard 기본값을 검증했습니다. 운영 워커에서 영어 quiet·일본어 long_cues 짧은 MP4의 0/+2.5초 보정을 다시 실행해 4/4 통과, 원본 MP4 SHA 불변을 확인했습니다. [배포 후 수치](rollout.json). 이는 전체 조건의 남은 실패를 해소했다는 의미가 아닙니다.
