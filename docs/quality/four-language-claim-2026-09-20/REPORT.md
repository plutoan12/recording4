# 네 언어 전체 정확도 개선 주장 검증

**판정: 입증되지 않음.** 자료 부족뿐 아니라 현재 후보에서 실제 회귀가 확인된다. 이 결론은 현재 후보와 표본에 한하며 향후 개선이 불가능하다는 뜻은 아니다. CI 통과는 음성 품질의 증명이 아니다.

## 기존 실측으로 확인한 반례

같은 120초 음원·정답에서 Community-1 → Sortformer v2.1 원음 결과를 비교했다. DER은 낮을수록 좋으며 정확도 백분율로 환산하지 않는다.

| 언어 | 기존 DER | 후보 DER | 판정 |
|---|---:|---:|---|
| 한국어 | 미측정 | 미측정 | 완전한 사람 정답 부재 |
| 일본어 | 54.760% | 18.577% | DER 감소, 발화 누락은 증가 |
| 중국어 | 10.890% | 13.033% | DER·발화 누락 증가 |
| 영어 | 15.612% | 43.372% | DER·발화 누락·화자 혼동 증가 |

원음→고정 음량 보정 비교도 후보 전체 채택 근거가 되지 않는다. Community는 중국어 무음 오검출, 일본어 누락, 영어 오검출·혼동이 늘었다. Sortformer는 중국어 세부 지표는 개선됐으나 일본어·영어 무음 오검출이 늘었다. 특정 언어의 좋은 모델만 사후 선택해 하나의 고정 후보가 개선됐다고 주장하지 않는다.

9개 비교는 기존 저장 점수에서 재계산했다. 새 음성 추론/새 표본/독립 재현 실험이 아니다. `results.json`에 원본 보고서·예측·정답 SHA와 모든 지표 차이를 보존했다. `python3 docs/quality/four-language-claim-2026-09-20/reproduce.py`로 재계산한다. 분모는 변경하지 않으며 1e-9의 부동소수 표현 차이만 동일 분모 확인에서 허용한다. 이 값은 음성 품질 허용 오차가 아니다.

## 입증에 남은 조건

1. 한국어 질문자 대사22구간과 특수표기27구간을 포함한 사람 전사/화자/겹말 검수. 자동 초안은 정답으로 사용하지 않는다. 비공개 검수 화면은 `recording4-evaluation-private/reference-link-20260920/REVIEW.html`에 있다.
2. 개발 자료에서 회귀를 줄인 하나의 후보를 고정한다. 현재 일본어·영어 등 표본은 결과를 이미 확인했으므로 이 자료로 수정한 뒤 같은 자료만으로 독립 최종 검증을 주장하지 않는다.
3. 각 언어의 다른 화자·여러 실제 대화를 사전에 선정하고 사람 정답과 입력 SHA, 구간, 정규화/채점 규칙을 고정한다. 현재 언어당 한 표본으로 언어 전체 성능을 일반화하지 않는다. 모델 학습에 포함됐는지 모르는 자료도 미포함 자료라고 주장하지 않는다.
4. 동일 후보로 기존11조건과 새 네 언어의 자동 STT CER, 문자 화자 정답/오배정/미확인, DER 누락·혼동·오검출을 함께 확인한다. 실패도 분모에 남긴다. 사람 단어 시각을 준 영어 oracle 점수는 자동 STT 정확도와 구분한다.

현재 운영 교체/main 병합은 보류한다. 새로운 기준을 느슨하게 설정하거나 평가 자료를 교체해 성공으로 바꾸지 않는다. 영어 사람 전사 연결/한국어 초안 준비는 [직전 보고서](../reference-link-2026-09-20/REPORT.md), 실제12회 추론은 [기존 실측](../multilingual-pilot-2026-09-20/REPORT.md)을 따른다.

검증: 코드 ca4ecbf의 Python·DER·웹·워커·스택 필수 CI 모두 통과 확인. 이번 변경은 결과 비교·문서만이며 모델 검사를 반복하지 않았다.
