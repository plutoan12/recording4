이번 파일 목록: `examples/asset-sources-english.json`. 수집 결과는 `.runtime/asset-library-english-01/`. 템플릿 원본과 그 변형·보조 파일이 따로 기록될 수 있으므로 파일 수는 디자인 종류 수와 다르다. 모든 외부 파일은 공개 재배포 검토 필요, 앱 실행 미검증 상태를 유지한다.

## recording4에 적용할 방향

- 실제 변환 코드 참고: AutoSubs의 Premiere 캡션 트랙/AE 텍스트 레이어 연결, OpenCaptions의 Resolve Text+ 처리.
- 편집 가능한 디자인 확보: 이번 Fusion 원본을 프로그램에서 열고 폰트·해상도·텍스트 길이별로 확인한 뒤 템플릿 변환 규칙에 반영.
- 나중에 이용자 다운로드를 제공할 카탈로그: 원본 커밋·라이선스·제3자 자산 조건을 검토한 자료와 직접 제작한 템플릿 중심으로 구성.
- 이번에는 자료 조사와 공개 파일 수집만 수행했다. 외부 앱 자동 설치, 회원 가입, 상용 플러그인 실행, 공개 마켓 배포는 수행하지 않았다.
