# 실제 영상 제작 우선 경로

화자 분리·DER/CER 연구는 선택 기능이며 제작의 선행 조건이 아니다. 현재 우선순위는 원본 등록 → 숏폼 편집 → 한국어 자막 → 얼굴 모자이크 → 결과물 검수다. 게시·예약은 결과물별 승인이 있어야 한다.

## 화면 사용

1. YouTube 링크로 가져오거나 이미 받은 원본 파일을 등록한다. 같은 원본이 있으면 재사용한다.
2. 편집기에서 원본을 선택하고 한국어 음성은 로컬 전사로 자막 초안을 만든다. 외국어 음성은 원문 전사 후 `자막만 번역 · 원음 유지`로 번역한다. 번역 공급자와 비용 설정은 별도이며 이번 경로 검증은 한국어 원본으로 수행한다.
3. 구간·세로 화면·제목·자막을 정한다. 여러 구간/배속/페이드/배경음악도 기존대로 사용할 수 있다.
4. 얼굴을 가리려면 `얼굴 자동 모자이크`를 켠다. 기본 도구는 deface이고 워커의 `privacy` 의존성에 포함된다. 가장자리나 작은 얼굴이 빠지면 `더 민감하게 감지`를 선택해 새 검수본을 만든다. 이 옵션은 deface의 검출 임계값 0.05·마스크 배율 1.5를 사용하며 기본값은 바꾸지 않는다. 얼굴이 아닌 영역까지 가릴 수 있고 완전한 비식별화를 보장하지 않는다. OpenScrub/EgoBlur는 서버에 별도 실행 파일과 가중치가 있을 때만 API에서 선택 가능하며 deface 민감도 옵션은 적용되지 않는다.
5. 렌더 후 완성 영상을 재생하고 자막과 모자이크를 확인한다. 편집 중 원본/한 장 미리보기는 모자이크 검수용이 아니다. SRT/VTT는 렌더된 자막과 같은 규칙으로 내려받는다.
6. 확인한 결과물 버전만 승인한다. 승인하지 않은 결과물은 업로드/예약 단계로 넘어가지 않는다.

모자이크 도구 실패·시간 초과·빈 출력은 렌더 실패로 남긴다. 편집한 비식별화 전 영상은 작업 임시 폴더에만 두며 모자이크 성공 후에만 결과물로 복사한다. 검출 결과가 존재한다고 모든 얼굴이 가려졌음을 보장하지 않으므로 최종 영상 검수가 필요하다.

선택형 EgoBlur Gen1은 정수 고정 FPS만 지원한다. 입력 FPS를 CLI에 명시하고 결과의 FPS·프레임 수가 달라지면 렌더를 실패 처리한다. 23.976/29.97 같은 소수 FPS나 시각을 확인할 수 없는 입력은 반올림하지 않으며 기본 deface를 사용한다. EgoBlur가 만든 가림 영상에 편집 완료 원음을 스트림 복사로 다시 결합한다. 이 연결의 FFmpeg 검증은 모델 대역을 사용했으므로 EgoBlur의 실제 가림 품질 검증을 대신하지 않는다.

## 배포 범위

운영 main `2e50815`를 기준으로 만든 `codex/video-delivery`의 [PR #40](https://github.com/plutoan12/recording4/pull/40)을 main `3151ecb`로 병합하고 Mac에 배포했다. main 통합 초안 #37의 화자 연구 전체는 포함하지 않고 필요한 모자이크 기능만 현재 멀티 컷 렌더와 제작 경로에 연결했다. 기존 작업자 checkout과 원본/모델/비밀 설정은 보존했다.

최종 PR의 Python·웹·Linux 워커·전체 스택 CI가 통과했다. 배포 후9개 서비스 실행, 기존 검수 영상 해시와 미승인 상태 보존, main 경로 자동 시작의 종료 코드0을 확인했다. 실제 Mac 재부팅과 사람의 자막·음질·전체 모자이크 검수는 완료하지 않았다. 실제 제작 결과와 상세 검증은 HANDOFF 최신 항목에 기록한다. 원시 음성·영상·전사와 자격증명은 저장소에 올리지 않는다.

## 후속 검수에서 발견한 문제

민감도 모자이크에서도 손에 일부 가려진 얼굴이 29.5초에 누락됐다. 제공 영상은 28.8–30.6초에 영역을 지정한 추가 모자이크를 적용한 **로컬 보완 검수본**을 만들었다. 이 파일은 서버의 기존 artifact와 다른 버전이며 기존 결과물의 승인을 재사용하지 않는다. 수동 모자이크 구간을 관리화면에서 입력하는 기능은 아직 없다.

워커에만 KSS가 설치된 조건에서 영상 자막과 API의 SRT/VTT가 다르게 분할되는 문제도 확인했다. 제작 브랜치의 후속 수정은 새 편집본 렌더 때 확정한 자막 파일을 보관해 그대로 내보낸다. 구운 자막은 실제 ASS에 저장된 시각까지 보존하고, 트랙 전용은 워커가 정한 문장/시각을 고정한다. 이전 결과물은 자동 복구하지 않으며 번역·더빙 작업의 기존 재계산 경로도 이번 수정에 포함하지 않는다. 후속 수정의 병합·배포 상태는 HANDOFF에서 확인한다.

후속 [PR #41](https://github.com/plutoan12/recording4/pull/41)을 main `9bcdd8c`로 병합하고 Mac의 API·워커 기반 서비스에 반영했다. 최종 PR CI·코드 검토가 통과했으며, 운영 API의 무료 합성 두 표본에서 구운 자막과 트랙 전용 모두 저장된 SRT/VTT와 다운로드가 바이트 단위로 일치했다. 각 결과의 전체 디코딩도 통과했다. 실제 보완 영상의 사람 청취와 전체 모자이크 검수는 여전히 남아 있다.

실제 결과·해시·검수 범위는 [2026-09-29 후속 보고서](quality/video-delivery-2026-09-29/REVIEW.md)에 기록했다.

## 구간 모자이크 보완

후속 제작 브랜치는 편집기의 **구간 모자이크 보완**에서 시각과 사각형을 저장할 수 있다. 배포 상태는 HANDOFF를 따른다.

1. `가릴 영역 추가`를 누르고 결과 영상 기준 시작·종료를 입력한다. 여러 구간과 배속을 적용했다면 이어 붙인 영상의0초부터 센다. 시작은 포함하고 종료 시각부터는 추가 가림을 해제한다.
2. 여백을 포함한 완성 세로 화면 기준 왼쪽/위쪽 위치와 너비/높이를 백분율로 입력한다. 위치 도식은 실제 영상이 아니며, 한 장 미리보기로 위치를 확인한다. 구간/화면 설정 변경 뒤에는 다시 확인한다.
3. 가림 크기는4–100px, 최대20영역이다. 자동 얼굴 모자이크와 함께 쓰거나 단독으로 쓸 수 있다. 자동 얼굴 감지 결과는 한 장 미리보기에 없으므로 최종 영상을 확인한다.
4. 숏폼 렌더를 실행하면 가림 설정을 저장한 별도 결과물 버전이 생성된다. 자동 모자이크 뒤에 지정 영역을 추가 적용하며 원음을 유지한다. 실패하면 미완성 영상은 결과물로 등록되지 않는다.

단일 구간을 번역·더빙 제작으로 넘겨도 지정 영역은 유지한다. 현재 제작 흐름은 여러 구간·배속을 지원하지 않으므로 해당 편집은 숏폼 렌더를 사용한다. 이 기능은 얼굴을 자동 추적하거나 기존 검수본을 승인하지 않는다. 이전 로컬 보완 MP4도 자동으로 서버 결과물로 등록되지 않으며, 새 코드 배포 뒤 새 검수본을 만들고 해당 버전을 확인해야 한다.
