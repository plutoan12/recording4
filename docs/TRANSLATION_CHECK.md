# 번역 품질 확인 (한국어 → 영어)

번역은 지금까지 **"호출이 성공했다"까지만** 확인했습니다. 무엇을 내놓는지는
잰 적이 없습니다. 이 문서는 잴 수 있는 것과 아직 못 잰 것을 나눕니다.

## 지금 아는 것

- 경로는 돕니다. 2026-09-18에 짧은 한국어 대본 → 실제 Google 영어 번역 →
  ElevenLabs 음성 → 합성 → 세로 숏폼 렌더까지 한 번 성공했습니다(번역·TTS 각
  1회, 합계 0.0120 USD). [인수인계](HANDOFF.md)에 기록이 있습니다.
- **품질 수치는 없습니다.** 그 기록은 "성공"이지 "얼마나 잘했나"가 아닙니다.
  테스트는 전부 대역이라 번역 내용은 검증 대상이 아닙니다.

## 자막 규칙은 언어마다 다릅니다 (CI가 매번 확인)

기본값은 Netflix **한국어** 지침에서 왔습니다(줄당 16자, 초당 12자). 글자 폭은
한글 1자, 라틴 문자·공백 0.5자로 셉니다. 그래서 한국어 숫자를 영어에 그대로
쓰면 이렇게 됩니다.

| | 한국어 기본값을 영어에 적용 | 영어 지침 |
|---|---|---|
| 줄당 | 32자 | 42자 |
| 읽기 속도 | 초당 24자 | 초당 20자 |

줄은 필요 이상으로 짧게 쪼개지고, 읽기 속도 검사는 오히려 느슨해집니다.
`pipeline.subtitles.LANGUAGE_RULES`가 언어별 지침을 폭 단위로 담고, 렌더가
목표 언어로 규칙을 고릅니다. **설정(`R4_SUBTITLE_*`)을 바꿨다면 그 값이
사람의 결정이므로 언어가 덮어쓰지 않습니다.**

CI `번역 자막 규칙 확인 (무료)`가 매번 돕니다. 참조 번역을 영어 자막 규칙에
넣어 줄 수와 겹침을 봅니다. 유료 호출은 하지 않습니다.

## 실제 번역 품질 재기 (유료, 사람이 실행)

자격증명이 있는 컴퓨터에서 돌립니다. 클라우드 세션에는 Google 자격증명이
없습니다.

```bash
R4_PAID_PROCESSING_ENABLED=true \
GOOGLE_APPLICATION_CREDENTIALS=~/.runtime/google-adc.json \
  python3 scripts/verify_translate.py \
    --pairs docs/samples/ko-en.json \
    --project <Google Cloud 프로젝트> \
    --allow-paid
```

**비용**: Google Cloud Translation은 100만 자당 20 USD입니다. 표본이 약 250자
이므로 0.005 USD 정도(1센트 미만)입니다. `--allow-paid` 없이는 호출하지
않습니다.

무엇을 재는가:

- **chrF**(문자 n그램 F 점수): 사람이 만든 참조 번역과 얼마나 닮았는지.
  단어 단위 점수(BLEU)는 어순이 자유로운 짧은 문장에서 심하게 흔들려 문자
  단위를 씁니다. 하한 0.40은 **품질 목표가 아니라 회귀 감시용**입니다.
- **문장 수**: 입력과 같아야 자막과 짝이 맞습니다.
- **자막 규칙**: 번역문이 영어 자막 규칙 안에 들어가는지. 번역이 맞아도
  자막으로 안 들어가면 화면에서는 깨집니다.

**수치 하나로 번역 품질을 말할 수 없습니다.** 스크립트가 문장별 원문·참조·
번역을 항상 함께 찍습니다. 수치보다 그쪽을 먼저 보세요.

## 표본

`docs/samples/ko-en.json`에 한국어 원문과 사람이 만든 영어 참조 번역 네 쌍이
있습니다. 참조는 제가 쓴 것이고 공인 번역이 아닙니다. 늘리거나 바꾸려면 같은
형식(`source`, `reference`)으로 추가하세요. 표본이 늘면 수치가 덜 흔들립니다.

## 아직 못 잰 것

- 긴 대본, 구어체, 고유명사, 존댓말 어조. 표본 네 문장으로는 알 수 없습니다.
- 더빙까지 갔을 때의 길이 맞춤. 번역문이 길어지면 음성이 원본 길이에 안
  맞습니다. 그 조정은 별도 단계이고 여기서 재지 않습니다.
- 영어 외 목표 언어. `LANGUAGE_RULES`에 한국어와 영어만 있습니다. 모르는
  언어는 설정값을 그대로 씁니다(추측해서 바꾸지 않습니다).
