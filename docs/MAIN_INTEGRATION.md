# main 통합 검토

이 문서는 별도 개발 브랜치에 누적된, 이미 구현·검증된 변경을 main에 통합하기 위한 검토 범위를 정리합니다. 새 기능을 운영에 배포했다는 뜻은 아닙니다.

- 통합 시작점: PR #35 병합 후 `b6f1525` (PR #34 HEAD).
- main 대비: 18커밋·99파일. 보고서·공개 수치 JSON이 큰 비중을 차지합니다.
- main 병합 계산 결과 충돌 없음, 결과 트리는 시작점과 동일합니다. 로컬의 다른 작업자가 수정 중인 단어 자막 기능은 포함하지 않습니다.

## 운영에 들어가는 동작

- 싱크 보정 근거가 부족하거나 원문 정렬과 충돌하면 거부합니다. 보정 방식과 원문 언어를 선택할 수 있고 처리 중 대본이 바뀌면 저장을 중단합니다.
- 화자는 단어별로 검수하고 정상적으로 정렬된 단어를 보존합니다. 실제 겹말은 검수 표시를 유지합니다. 요청 버전과 결과 버전을 연결합니다.
- HF 토큰만 있는 CI에서도 화자 검증용 음원을 먼저 준비하도록 조건을 수정했습니다.

## 자동 채택하지 않는 실험

분리 음성 재시도, 기존 배정 재검사, DiCoW, 중국어 간체 변환, 검수 후보 생성은 검증 도구입니다. 운영 기본은 화자 처리 1·2단계를 유지합니다. 품질 판정의 통제 표본 개선은 배포 허가가 아닙니다.

## 근거와 남은 위험

- 화자 11조건 4,389자: 3,069/109/1,211 → 3,767/109/513(정답/오배정/미확인). 기존 오배정 109자는 남습니다.
- 싱크 140조건: 112통과/28거부. 3.94초 오차를 성공으로 처리하던 오류를 차단했지만 기존 통과 19개도 거부합니다. 전체 성공률 상승으로 표현하지 않습니다.
- 실제 영어 회의에서 예측 화자 수 부족과 DER 34.49%가 남습니다. 실제 한·일·중 대화는 별도 평가가 필요합니다.
- 기존 최종 Python 486통과/5skip, Ruff 통과. PR #35의 웹·워커 이미지·스택 CI 통과. 통합 PR의 최신 CI와 Claude 누적 차이 검토를 확인한 뒤 main 병합을 판단합니다.

상세 수치는 `docs/quality/`의 원래 보고서를 유지합니다. 원시 음원·전사·모델·비밀값을 이 통합 PR에 추가하지 않습니다.

## 누적 차이 Claude 검토 확인 (04시대)

- 실제 확인·수정: 원문 언어 또는 stable-ts가 없을 때 빈 단어 목록으로 분석 성공 처리되던 경로를 명확한 오류로 바꿨습니다. API도 원문 언어가 없으면 작업을 만들지 않습니다.
- 실제 확인·수정: 진행 중인 화자 분석의 언어 또는 대본 버전과 다른 요청은 기존 작업으로 합치지 않고 409로 알립니다. 동일 요청의 중복 방지는 유지합니다.
- 지적에서 제외: 대본이 없는 화자 요청은 이미 409 검사가 있어 500 지적은 해당하지 않았습니다. 기존 테스트로 확인했습니다.
- 추가 확인 과제: 공백 포함 일·중 자막의 단어 경계 처리, 자막별 FFmpeg 시간 제한과 부분 실패 처리, 싱크 중복 요청의 버전 비교, 경계 근거 수치 표시, 긴 영상의 검수 응답 크기와 반복 디코딩 비용. 이 과제까지 모두 해결했다고 표현하지 않습니다.
- 이번 수정 후 Python 전체 **489통과/5skip**, 변경 파일 Ruff 통과. 실제 모델 검사를 반복하지 않았으며 정답/오배정 지표 개선을 주장하지 않습니다.

PR #34의 b6f1525 CI는 모두 통과했지만 위 사전조건 수정이 선행되어야 합니다. 수정 PR을 #34 브랜치에 반영하고 최신 CI를 다시 확인한 다음 #34 병합과 main 통합을 진행합니다. main PR은 초안을 유지합니다.
