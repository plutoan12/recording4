## 기본 방향

- GitHub: 코드 관리, 테스트, 배포, 수동 작업 요청.
- 관리 API와 DB: 작업·버전·승인·예약의 기준.
- 영상 저장소: 원본, 중간 산출물, 완성 영상 보관.
- 별도 워커: AI 호출과 FFmpeg 처리.
- 관리화면: 대본 수정, 미리보기, 검수·승인.
- YouTube: 승인된 결과물을 비공개 업로드한 뒤 공개 예약.

기술 선택은 구현 전 추천안이며 계정 개설·유료 서비스 사용 승인을 뜻하지 않습니다. 초기에는 관리자 1명, 채널 1개, 작업별 대상 언어 1개를 가정합니다.
