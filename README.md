# recording4

영상 원본을 등록하고 번역·더빙 영상을 만들거나 롱폼을 숏폼으로 편집한 뒤, 검수·승인을 거쳐 YouTube에 예약 공개하는 파이프라인입니다.

**현재 상태: Mac 로컬 서버 가동, 실제 STT·숏폼 편집과 Google 번역·ElevenLabs 더빙 샘플 검증 완료. YouTube 계정 연결과 실제 샘플 비공개 업로드·처리 완료를 확인했으며 공개 예약 검증은 남아 있습니다. 결과물별 검수·승인을 유지합니다. 최신 운영·예산 상태는 [인수인계](docs/HANDOFF.md)를 참고하세요.**

처음 참여하는 사람이나 AI는 프로젝트 범위 → 시스템 설계 → 기술 선택 → 구현 계획 → 인수인계 순서로 읽습니다. 코드를 실행하려면 [개발 환경](docs/DEVELOPMENT.md)을 봅니다.

YouTube 링크를 파일로 가져오려면 관리화면의 **YouTube 링크로 가져오기**를 사용하세요. 지원 범위와 한도는 [사용 안내](docs/CONNECTED_WORKFLOW.md#youtube-링크로-원본-등록)에 정리했습니다.

명령줄에서 자막 파일을 검사·변환하거나 자막 모양 템플릿을 골라 영상에 구우려면 `r4-subtitles`를 씁니다([자막 파일·템플릿 도구](docs/SUBTITLE_TOOL.md)). 편집기의 **자막 템플릿** 선택도 같은 템플릿입니다.

이미 있는 자막 파일(SRT·VTT·ASS)을 대본으로 들이려면 편집기의 **자막 파일 가져오기**를 사용하세요. 자막을 파일로 쓰려면 관리화면의 **자막 SRT·VTT 내려받기**를 사용하세요. 숏폼 편집본은 렌더 결과 줄에, 번역·더빙 작업은 작업 화면에 있습니다. 영상에 구운 자막과 같은 내용이며 시각은 출력 영상 시작이 0초입니다.

## 기본 방향

- GitHub: 코드 관리, 테스트, 배포, 수동 작업 요청.
- 관리 API와 DB: 작업·버전·승인·예약의 기준.
- 영상 저장소: 원본, 중간 산출물, 완성 영상 보관.
- 별도 워커: AI 호출과 FFmpeg 처리.
- 관리화면: 대본 수정, 미리보기, 검수·승인.
- YouTube: 승인된 결과물을 비공개 업로드한 뒤 공개 예약.

기술 선택은 구현 전 추천안이며 계정 개설·유료 서비스 사용 승인을 뜻하지 않습니다. 초기에는 관리자 1명, 채널 1개, 작업별 대상 언어 1개를 가정합니다.
